# Agent Note: 限制原生 transcript 布局并恢复叶子文字选择

Status: proposed

[English](2026-09-13-bounded-native-transcript-layout.md) | 中文

## 问题

短会话也可能在表格重新排版、工作台宽度变化和安装新轮次的组合过程中卡住原生界面。静态历史加载探针没有复现这个转换。主线程采样指向 SwiftUI 的惰性栈布局；后端可能已经完成，界面却仍持续忙碌。另外，禁用原生文字选择使用户无法拖选对话文字。

## 提案

当前源码候选仅将 [ArkRootView](../../../../integrations/jiuzhang/native/Sources/JiuzhangShellUI/ArkRootView.swift) 中主 transcript（文本记录）的 `LazyVStack` 替换为 `VStack`。现有[渲染窗口](../../../../integrations/jiuzhang/native/Sources/JiuzhangShellUI/ArkChatRenderWindow.swift) 仍负责限定挂载行：稳定状态最多 400 条，流式状态为 96 或 160 条。稳定行标识、轮次锚点、前后翻页和返回最新位置保持不变。这不会挂载完整会话。

[Markdown 叶子节点](../../../../integrations/jiuzhang/native/Sources/JiuzhangShellUI/NativeMarkdownGFMView.swift) 和思考文字使用标准 SwiftUI `textSelection(.enabled)`。这覆盖用户与助手共用的段落、标题、列表正文、代码和表格单元格，不新增覆盖整个 transcript 的选择所有者。现有整条消息与完整代码复制操作继续保留。

同一 Markdown 来源中相邻的普通段落共用一个可选择的 `Text`，复用已解析的 inline 值和现有助手行缓存。每组最多包含八段、4,096 个 UTF-16 单元和 256 个 inline 节点，身份采用原始首块索引。代码、表格、标题及其他块类型会结束当前组。原有超大段落保持独立。普通文档渲染器采用相同分组规则；这不会连接不同消息或来源块。

这仅部分替代[启动与 Markdown 批处理](../../implemented/bug-fix/2026-09-08-native-startup-and-markdown-batching.zh.md) 中有限惰性布局的细节；其解析与发布决策仍然有效。此前的[根布局对齐边界](../../implemented/bug-fix/2026-08-29-ark-native-risk-boundaries.zh.md) 也仍需保留。两篇记录均不满足整篇归档条件。

## 验证边界

相同的合成完整根视图 Release 转换未加载 WebKit 网页：旧容器在 25.02 秒后超时，子进程消耗 17.17 秒 CPU；有限 `VStack` 在 15.73 秒内正常退出，子进程消耗 1.04 秒 CPU，并记录 54 次心跳。独立的 100 轮 Release 场景在 8.32 秒内通过，子进程消耗 3.37 秒 CPU。这些是受控诊断运行，不是应用延迟分位数或正式性能提升百分比。

UI 目标构建通过。原生鼠标拖选探针在真实文字叶子节点中选中了 `{0,19}` 范围。其私有剪贴板 `writeSelection` 判定返回 false，因此该探针不能证明产品 Cmd+C 成功或失败。真实候选拖选复制、已复现的交互序列以及 60 分钟验收仍待完成；本文不记录已交付的正式版本。

## 考虑过的替代方案

**因为静态加载通过而保留惰性容器。** 这些探针遗漏了出错的宽度变化与轮次安装组合；受控转换才是相关的对照。

**禁用宿主固有尺寸计算。** 匹配实际四边约束宿主的基线在未修改尺寸选项时已经通过，因此没有对应的失败证据支持修改根宿主约定。

**使用无限制的立即布局 transcript，或全局禁用选择。** 前者丢弃现有挂载预算；后者移除用户要求的交互。复用渲染窗口和原生叶子选择可以避免这两项代价。

## 验收标准

重新构建的候选必须在表格展示、工作台折叠与展开以及下一轮流式回复期间保持响应，保留轮次导航和双向历史可达性，并支持对用户及助手文字实际拖选后使用 Cmd+C。记录发布验收前，须完成计划中的 60 分钟活跃与空闲运行，并保留 CPU 和内存收据。

## 风险

立即布局栈仍会测量至现有窗口上限；它既不是总内存上限，也不能证明帧耗时目标。分组后的行包含多个原始段落，因此有限文字预算和组合布局回归都很重要。不能保证跨独立组、其他块类型或消息的原生连续选择。合成测试成功不能替代用户真实窗口、保存状态与无障碍交互的验证。
