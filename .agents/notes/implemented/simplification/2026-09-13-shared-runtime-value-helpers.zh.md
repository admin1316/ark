# Agent Note: 共享运行时值工具并保留归属检查

Status: implemented

[English](2026-09-13-shared-runtime-value-helpers.md) | 中文

## 问题

Session JSON 校验与 LLM 深度冻结重复实现了值工具的逻辑。Settings 结构相等比较有一处重要差异：值工具允许继承属性满足键查找，而 Settings 要求对象自身的属性。如果替换 Settings 实现时不保留该条件，就会削弱变更检测和提供方事务比较。

## 决策

`dsh-util-values` 统一负责无损 JSON 校验与快照、迭代深度冻结及 JSON 结构相等比较。Session 现有 JSON 导出与 LLM 现有 `deepFreeze` 导出转发到这一所有者。Settings 导入并重新导出共享相等函数；比较通过 `Object.hasOwn` 要求记录自身的键匹配。

公共模块路径与泛型签名继续可用。JSON 校验仍拒绝负零、稀疏数组、特殊原型、循环值及会丢失的自身属性，同时允许跨 JavaScript realm 的普通值。快照仍只读取每个属性一次，并传播 getter 抛出的错误。冻结仍防护循环，并让活跃的取消信号保持可变。Settings 独立的 schema 结果冻结器保持原有生命周期。

三个消费包将值工具声明为运行时依赖，并引用其编译项目。不引入新的运行时注册表、状态、定时器或服务。

## 考虑过的替代方案

**保留重复实现。** 持久化、请求发布与 Settings 消费方中的修复可能因此分歧。

**不修改值工具就转发 Settings 相等比较。** 匹配原型继承的值可能掩盖不同的自身键集合。共享谓词保留 Settings 更严格的归属检查。

**把每个调用方都改到新公共路径。** 现有公共导出可以直接转发，无需第二套实现或调用方改动。

## 后果

Session JSON 与 LLM 冻结行为测试继续通过原有公共导出执行。相等比较回归覆盖值工具和 Settings 两个导出，包括继承属性、嵌套继承属性及空原型记录。提供方事务与离线迁移测试覆盖下游比较。这些检查不证明全仓库构建或 Native 正式发布验收。
