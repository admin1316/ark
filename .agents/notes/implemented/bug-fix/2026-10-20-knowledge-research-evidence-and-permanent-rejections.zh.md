# Agent Note: 研究引用归属与持久提取拒绝

Status: implemented

[English](2026-10-20-knowledge-research-evidence-and-permanent-rejections.md) | 中文

## 问题

实际搜索结果不能阻止模型虚构其他引用、把生成页标为正式知识，或不返回任何可发布页面。通用失败冷却也会在每次到期后重新执行不支持或损坏的本地文件。只把永久失败保留在有界队列历史中，会在回收或重启后丢失保护。

## 决策

研究所有者把搜索 URL 视为权威身份，把模型响应视为不可信 Markdown。它在保留查询语义的前提下规范化无凭据 HTTP(S) URL，校验普通及引用式链接属于真实搜索集合，只发布含已知引用的页面。Host 生成候选/研究身份、日期和实际引用的来源。空或无效输出、无效引用、全部碰撞或写入失败具有不同错误码；部分成功保留警告。搜索摘要明确标为不完整证据，URL 匹配和传输成功均不证明页面主张为真。

本地提取通过独占 worker（工作线程）传递类型化错误，拒绝不支持、二进制、损坏、过大和空输入。失败字节及实际解码策略标识永久拒绝，既有来源处理缓存独立于有界队列历史保留它。已提交拒绝抑制对应的旧恢复租约，新准入身份保留用户显式重试。内容或解码策略变化允许另一次自动尝试；暂时失败和未分类旧错误保留原冷却规则。

原生客户端校验来源数量及每页关联，拒绝零页完成，并展示已记录研究 URL 及搜索摘要限制。打开来源复用隔离的工作台浏览器，并消费一次性导航意图。浏览器继续拒绝非 HTTP(S) 或带凭据 URL，不获得 Ark 凭据或本地文件桥接。

## 考虑过的替代方案

**相信 prompt 和模型 frontmatter。** 指令不能证明引用成员关系，也不能覆盖模型提供的正式知识状态。Host 校验和字段生成执行实际发布决策。

**抓取每个来源或调用另一个模型核验。** 当前研究使用搜索摘要；增加抓取或第二意见会改变延迟、费用和信任处理，不能替代诚实的证据标签及确定性 URL 成员校验。

**只在任务历史保留永久拒绝。** 有界历史有意回收终态记录；来源处理文件拥有重复执行抑制，并已共享准入容量、持久化和恢复检查。

**永久封锁文件名。** 替换后的文档或修正后的解码器可能使输入可处理。内容和策略指纹只在拒绝原因仍适用时保留拒绝。

## 验证

真实 YAML/Loader 组合使用已注册 LLM（大语言模型）运行时、独占执行器和合成外部搜索/模型，无密钥快照覆盖无效引用、受控成功及碰撞失败。聚焦测试覆盖链接定义、危险 URL、强制元数据、历史回收/重启后不变拒绝、新重试准入及缓存/队列崩溃窗口。原生契约校验来源解码和持久页面来源；候选交互仍需独立验收。

## 影响

无效页面不产生发布或评审项，不变的永久文件失败不产生重复模型调用。直接 Markdown 解析器依赖替代临时链接匹配。既有队列/缓存文件承载额外身份，不新增状态文件。PDF/Office 提取及事实/全文核验仍不可用。[显式路由决策](2026-10-20-ark-explicit-routing-and-durable-input.zh.md)保留独立连接、项目、取消和输入持久性理由；[摄取决策](../architecture/2026-08-19-knowledge-wiki-contract-aligned-ingest.zh.md)保留更广泛的队列和正式写入设计，两者继续有效。
