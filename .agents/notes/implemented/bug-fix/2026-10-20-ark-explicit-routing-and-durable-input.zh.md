# Agent Note: Ark 显式路由、项目归属与持久输入

Status: implemented

[English](2026-10-20-ark-explicit-routing-and-durable-input.md) | 中文

## 问题

知识操作若把共享密钥与固定外部端点组合使用，可能把凭据发给错误服务。可变的当前项目选择可能在异步边界后重定向工作。把二进制容器当作 UTF-8，或在零来源时综合研究，会使传输成功看起来像知识处理成功。在提示词持久接收前清除草稿，可能丢失唯一可重试的输入。启动和关闭也需要有界的归属管理，不能只依赖进程仍存活或任务句柄已取消。

## 决策

知识文本与图片任务独立选择已注册的 LLM（大语言模型）路由，复用其预备调用的协议与凭据 owner。向量检索要求独立、完整的端点、模型、提供方标签与凭据引用；重定向不能转发凭据。`knowledge-wiki` 设置命名空间通过修订号／CAS 持久保存路由引用。图片配置为空时保留本地媒体，不生成说明；向量配置为空时使用本地关键词检索。多阶段任务在第一次请求前准备两个模型调用，同时保留提供方的凭据值轮换约定。[包参考](../../../../packages/host/knowledge-wiki/README.zh.md)拥有配置与文件格式限制。

原生向量凭据轮换先写入新的独立引用，再以 CAS 发布整条连接，不覆盖活动连接的原有引用。CAS 失败或响应丢失时保留新的本机凭据，因为连接可能已经提交；刷新公开设置可核对结果，避免删除可能仍在使用的凭据。

原生连接编辑器沿用周围设置卡片的样式，对齐模型选择，并将可选向量字段收在折叠区域。可见字段标签和明确的保存操作保留凭据用途与显式提交语义。

原生知识搜索与页面选择通过现有操作 owner 取消已被替代的传输请求。清除搜索或切换项目也会取消这些读取。代次检查仍拒绝过期响应，但不能替代取消已不需要的工作。

知识导入保留单一串行 drain，每个调用方只等待自己项目内的任务结果。品牌化准入身份将持久取消意图绑定到已接收的那次尝试。公开队列取消仅作用于待处理任务；项目撤销拥有活动任务的取消职责。原子批次准入、有界终态历史和一致的读写字节预算，防止队列写出自身无法恢复的状态。来源完成、取消和重试处置在历史回收后仍保留。恢复先验证，再发布任务和项目选择。

研究仅在项目、主题和连接快照相同的范围内共享在途操作，并限制并发。总期限从本地搜索凭据预检之前开始；到期取消 owner，工作真正停止前仍占用容量。原生请求冻结 Host 公布的预算与传输宽限，使用绝对期限，并按操作身份拒绝过期响应。普通 RPC 期限不变。研究候选通过完整临时文件发布，不替换已有页面。搜索预检在任何付费查询扩展前等待延迟解析的本地凭据；同步提供方选择不能证明异步凭据确实存在。

会话投影存储为每个会话保留一次活动写入和最新待写快照，实时检查点与冷读回写共用该 owner。写入失败保留待写状态以供重试。组合 disposer 在释放存储域之前等待 writer 排空，失败时也释放域。这合并的是可丢弃的派生快照，不删除规范会话事件；必需事件持久化的背压仍是独立的准入设计项。

每个项目级请求都携带注册表签发的 `projectContext`。Host 在接收时将其一次解析为不可变的项目执行上下文；后续选择变化不能重定向读取、写入、审阅、队列或研究工作。移除项目会撤销令牌并取消所属操作；Host 重启使所有令牌失效。原生响应还检查项目与加载代次。自动会话摘要在模型执行前绑定已注册的次级会话工作区及其生命周期。候选写入共用受限文件系统 owner，拒绝上级目录中的符号链接。文件提取在模型分析前拒绝不支持、二进制、格式错误或超限的输入。研究在扩展查询前预检共享 web 服务，并在综合或发布前要求可引用的来源；部分结果保留警告。

普通提示词提交在 Host 确认持久接收前，保留已同步、仅属主可访问的草稿与附件日志。调用方稳定的调用身份与内容摘要对照已记录的收件箱回执，使结果不明的重试去重，包括冷会话。Host 在返回接收确认前刷新所属会话。原生清理比较已提交内容与当前草稿，因此后续编辑不会消失。新会话迁移在创建会话期间保留可恢复性。单一 writer 对每份草稿只保留最新待写快照，发送和退出等待持久保存。自动保存与发送中内容的附件相同时共享一份附件日志，各自的持久指针仍独立拥有恢复职责；被替换日志仅在新指针持久发布并检查引用后回收。这些保证不会使任意斜杠命令副作用幂等，也不替代已接收图片的规范对象存储。

每代后端启动有一个就绪期限，默认三十秒，可由已签名元数据覆盖，并拥有一个代次身份。就绪、失败、退出与关闭应用使等待失效；超时停止自己拥有的进程，回收后才进入恢复。现有的有界重启和稳定窗口规则仍为权威。后端输出回调保留其启动身份。关闭流程取消并等待知识加载与轮询，worker 结果只结算一次，已取消或过期的回退结果不能覆盖另一个项目。

Ark 的显式测试清单拒绝未登记、缺失与重复测试。必需 CI 分别执行可移植回归、Swift 契约与隔离的 macOS 打包／安装行为。仅处理元数据的评测工具定义 24 个合成任务和两轮运行，区分未执行、跳过、合成与实测观测。目录条目和离线报告都不认证提供方，也不授权付费调用。[工程说明](../../../../integrations/jiuzhang/docs/engineering.md)拥有命令与安装验收说明。

## 曾考虑的替代方案

**所有服务复用聊天密钥。** 独立寻址的向量或视觉端点不会继承另一个提供方凭据的归属。显式路由选择避免意外跨服务披露，也允许诚实呈现未配置状态。

**每次 await 后读取当前项目。** 相对路径在另一个项目中可能指向不同文件，即使两份初始内容一致也如此。不可变的接收身份使归属保护独立于路径和内容相等性。

**乐观清除输入，报错后恢复。** 进程可能在错误处理前消失，失败响应也不证明 Host 拒绝输入。持久草稿加持久回执保留可恢复性，不重复已接收的工作。

**把非空提取或成功的模型响应当作研究成功。** 二进制噪声和零来源综合同样满足这些弱条件。格式验证与来源要求在进一步付费工作或发布前拒绝误导结果。

**先改写活动凭据再切换连接。** 并发请求会观察到旧端点和新密钥，CAS 拒绝后错配还可能持续。新的独立引用避免中间态错配，也避免跨服务回滚误删已提交连接的凭据。

**只扩展人工发布检查。** 未登记的测试可能静默停止执行。显式清单与必需 CI 任务发现此类遗漏，同时保留独立的原生交互与发布决定。

**丢弃排队的会话事件来限制内存。** 这些事件是持久对话的权威记录。只有已被替代的派生检查点可以合并；必需事件存储需要明确的上游准入和失败处理。

## 后果

未配置的云功能会明确停止或使用本地关键词检索。PDF／Office 导入在没有验证过的解析器时，于分析前失败。后端替换后必须重新获取项目令牌。持久本地草稿消耗有界磁盘空间，需要区别于已接收消息对象的清理。异常缓慢的机器可能需要覆盖三十秒默认启动期限。

定向契约覆盖错误服务的凭据路由、项目切换、不支持的二进制输入、零来源研究、持久重试接收、独立进程草稿恢复、就绪归属与测试清单失败。契约存在和单项结果不证明最终候选的原生交互、安装包、隐私或发布验收。正式替换和 Git 发布仍是需要用户分别明确决定的操作；本笔记不记录最终候选结论或真实模型质量结果。
