# Agent Note: 投影可选锁路径并保留退出身份校验

Status: implemented

[English](2026-10-19-native-candidate-lock-and-exit-identity.md) | 中文

## 问题

Ark 的运行时计划从根 pnpm 锁文件推导外部依赖图，收据则校验按平台安装后的锁文件。pnpm 在 macOS arm64 上保留外平台可选包的元数据，但裁去其后代依赖边。要求这些不可达的后代会使正确锁定的安装无法通过收据校验：`sharp` 的 WebContainers 可选分支要求一个缺失的 `@emnapi/runtime` 解析结果。

父进程死亡与 `SIGTERM` 竞态测试可能在 macOS 已将保留进程的 argv 替换为 `(node)`、而 `ps` 尚未报告僵尸状态或移除该行时观察到它。立即拒绝该观察会使正常退出导致测试失败；把任意 argv 丢失都当作退出，或向身份已变化的 PID 发信号，则会削弱进程所有权校验。

## 决策

纯函数 [`deriveArkExternalLockGraph`](../../../../integrations/jiuzhang/src/runtime-plan.mjs) 为 Ark 的 `darwin-arm64` 目标投影根锁图。它保留精确的包解析结果、完整性值和外平台可选父节点元数据，但省略仅通过不受支持的可选路径可达的后代依赖边。可选性沿完整路径传递。即使此前已进行可选访问，必需访问或另一条受支持的路径仍保留可达后代。[收据校验器](../../../../integrations/jiuzhang/src/runtime-closure.mjs) 保留精确的完整性和解析结果校验。

[进程身份辅助函数](../../../../integrations/jiuzhang/tests/helpers/process-liveness.mjs) 将启动时间相同的僵尸进程视为已退出，不向它发信号。对于启动时间相同且与括号包裹的可执行文件名精确匹配的占位符，异步辅助函数最多观察十次，间隔 10 ms。该占位符从不授权发送信号。只有新鲜观察行与保留的启动时间、可执行文件和完整 argv 全部匹配时才授权发送信号；行不存在或启动时间相同的僵尸状态则确认退出。其他身份变化立即失败，持续存在的占位符则在有界观察结束后失败。

[生命周期测试](../../../../integrations/jiuzhang/tests/lifecycle.test.mjs) 将启动时间相同的非僵尸进程保守地视为存活，即使 argv 不可用。这能避免清理断言在模糊区间内误报成功。原始失败运行没有记录 `ps` 状态，因此无法还原其精确状态；本机复现独立证实了从睡眠状态占位符到进程行消失的转换。

## 考虑过的替代方案

**放宽收据的解析结果或完整性校验。** 这会接受真实的锁定漂移。按包管理器的行为投影可选路径，保留了独立校验器的权威性。

**删除全部外平台包，或无条件遍历它们。** 删除父节点会丢失 pnpm 保留的锁元数据。遍历全部子节点会要求 pnpm 不安装的包，而全局裁去一个此前通过可选路径访问的节点，可能抹掉其他路径可达的后代。

**忽略进程身份错误，或仅按 PID 发信号。** 两者都可能掩盖存活的遗留进程，或向复用的进程发信号。有界复察仅处理已识别的退出占位符，并保留每次发送信号前的严格身份校验。

## 后果

[锁图回归测试](../../../../integrations/jiuzhang/tests/runtime-plan.test.mjs) 固定了父节点元数据保留、不可达子节点排除、受支持的替代路径、可选性继承，以及先可选后必需的访问行为，同时确保输入图不被修改。生命周期回归覆盖新鲜匹配行、PID 复用、argv 与可执行文件漂移、持续模糊状态、保守存活判断，以及由暂停父进程保持未回收状态的真实子进程。启动器关闭协议保持不变；竞态测试的观察与信号授权更加精确。

源码检查确立了这些机制。正式运行时打包成功、候选安装态校验与原生交互验收仍是独立证据；仅源码测试不能确立发布就绪，也不能证明与旧应用一致。
