# Agent Note: 提供方验证与凭据标头管理归属

Status: implemented

[English](2026-09-09-provider-verification-and-header-ownership.md) | 中文

## 问题

公开模型目录可以使用任意凭据回答，因此元数据请求成功不能证明认证成功。取消不配合的探测也不能证明请求已经停止。通用标头字典中的明文凭据还可能绕过 schema 角色隐藏机制，或与普通连接设置一起持久保存。

## 决策

现有 [LLM（大语言模型）管理层](../../../../packages/llm/llm/src/index.ts)负责精确路由验证的准入、时限和取消结算。被取消的操作在实际结束前保留路由和模型预约。宽限期超时会报告仍在运行的工作，不会宣称完全停稳。管理层 dispose（资源释放）停止准入，并等待同一组工作。适配器默认钩子声明不支持元数据验证；管理层随后执行明确分类的单 token 握手，不携带会话历史，并丢弃输出。

[pi-ai 适配器](../../../../packages/llm/llm-pi-ai/src/adapter.ts)在解析凭据前捕获当前 profile。[元数据验证器](../../../../packages/llm/llm-pi-ai/src/verification.ts)检查精确模型 id，限制声明与实际流式响应字节数，拒绝重定向，然后移除凭据进行对照请求。对照请求返回 401 或 403 才能将需要认证的元数据与单纯可达性区分。响应清理失败不能替换已经确定的 HTTP 或体积超限失败。

[标头解析器](../../../../packages/llm/llm-pi-ai/src/headers.ts)分别接纳公开字段与显式凭据引用。现有 Credentials 服务在请求时解析引用值。无凭据对照请求移除全部显式凭据标头，包括看似公开的提供方专用名称。非空明文疑似凭据标头保留磁盘数据，但阻止路由激活，只暴露不含值的迁移字段，并拒绝新写入。Settings 通过同一个管理层隐藏函数投影已解析层、base 层和用户层。空 Authorization 保持为非秘密协议覆盖；不区分大小写的重复名称在分发前被拒绝。

这些规则补充[提供方日志决策](2026-09-09-provider-journal-recovery.zh.md)与[原生风险边界](2026-08-29-ark-native-risk-boundaries.zh.md)：前者仍负责持久配置变更和恢复，后者仍负责打包与应用验收。两份记录均未被取代。

schema 接纳不等于字段公开：Schemastery 会保留未声明字段。因此，同一个隐藏函数通过实时 Config schema 投影保留的根数据和 profile 数据，隐藏每个未声明字段，不猜测凭据名称。已声明的字典键、模型能力字段和联合类型各分支的公开字段仍可使用。格式非法的已声明值和引用、非 JSON 或循环结构均会被拒绝，不回显数据。profile 处理要求包含不带值的相对路径与部署层归属。原生迁移必须明确同意并提供新凭据，且复用现有事务；用户层编辑不能移除部署层字段。

模型容量越过 Host 结果边界前必须是正安全整数。原生解码器还使用可失败的精确整数转换，避免格式非法的端点元数据使应用陷入崩溃。外部列表的无效容量保持未知，不虚构更小的模型上限。原生目录发现会取消此前任务，并忽略迟到的已取消结果；读取内置目录不携带凭据。

## 考虑过的替代方案

**把目录成功视为认证成功。** 公开目录无法区分无效密钥与有效密钥；对照请求未证明认证要求时，响应必须只表示可达性。

**请求取消时立即释放预约。** 适配器可能忽略取消；过早释放会在第一个请求仍运行时允许另一个请求进入。

**仅按名称过滤对照请求标头。** 凭据可以使用任意提供方标头名称。显式引用来源而非单独的启发式判断，才能确定所有必须移除的值。

**发现时擦除存储的明文标头。** 读取不能静默破坏用户配置。管理层隐藏值并阻止激活，直到显式配置变更提供安全引用。

**仅依赖配置类型或原生整数转换。** 未知配置字段会在 schema 解析后保留，而 JavaScript 数值可能超出 Swift 整数范围。数据管理层在暴露前校验实际值，原生消费方独立拒绝不安全的协议数值。

## 影响

元数据认证不能证明生成权限、模态支持或提供方未来可用性。不支持的探测可能消耗一次有界生成请求。不配合取消的工作保持为明确失败，并可能阻止干净退出。公开标头字段不能识别任意未声明的秘密；调用方必须为这些值使用凭据引用。按照现有 Settings 合并语义，base 层字典键仍需编辑组合配置才能移除。
