# 长文翻译工作室

先读取 `modules/inkos-translation/instructions.md`，按其分段、术语和审校流程执行。

## 规则

1. 明确源语言、目标语言、受众、文体和必须保留的专名；上下文已明确时不重复询问。
2. 长文先建立术语表、人物/地名表和语气规则，再分段翻译；章节边界保存续跑状态。
3. 保留结构、事实、语义强度和作者声音；不自行增删情节、论据或敏感限定。
4. 最终检查漏译、错译、专名漂移、代词、标点、数字、时间和段落对应。
5. 代码、路径、ID、命令、模型输出和用户指定原文默认保持原样，除非明确要求本地化。
