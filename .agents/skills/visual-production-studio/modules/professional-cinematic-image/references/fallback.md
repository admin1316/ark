# 模块: fallback（professional-cinematic-image 子模块，按需加载）

## 🔴 CHECKPOINT：情绪目标不明就先确认

情绪是本 skill 一切决策的锚点。**如果用户没说清想要什么感觉、或只丢来一个名词（"帮我画个城市"）——先用 6 步观众心理从上下文反推情绪；反推不出、或有多种明显不同的解读，就先用一句话问确认（"要孤独疏离，还是繁华喧闹？"）再写提示词。** 情绪定不了，后面每个参数都是瞎猜。上下文里情绪已明确时跳过此步。

## 失败模式与兜底（if-then）

出图或写词不对劲时，按「触发条件 → 一线修复 → 仍失败兜底」对症下药：

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 出图仍脏 / 噪点多 / 塑料感 | 正面加 `干净低噪、自然肤质、克制锐度`；删掉 `8k / ultra detailed / hyper sharp` 及一切"做旧/磨损/gritty" | 只留"细腻自然颗粒"一处质感词，其余质感词全删；见 recipes「太脏」 |
| 出图偏离主体、变成通用电影场景 | 回到用户原主体，电影语言只加在光/构图/色上，绝不替换主体 | 主体名词提到提示词最前面 + 明确"画面主角是 X" |
| 用户只给一句话、没说情绪 | 走 6 步观众心理反推 + 据情绪表选参数 | 触发上面 🔴 CHECKPOINT，问一句确认情绪 |
| 想要胶片感却出脏 | 确认没同时写"绝对干净/超清晰"——两者冲突 | 改"细腻低噪 + 轻微自然颗粒"，删重度做旧 |
| 画面套路化（全片青橙 / 无动机光） | 逐项检查每个光/色是否有场景动机，无动机就删 | 换成场景真实光源驱动的配色，见 recipes 色彩配方 |
| 用户给了【锁定模板】却想改 | 严格只填字段、不增删重排，只优化字段内措辞 | 每个字段只填一个确定值，不留 or / 斜杠 |
| 情绪与惯例冲突（如低机位却要孤独） | 以情绪目标为准、惯例让路（低机位 + 空旷 + 冷光也能孤独） | 查反查表确认所选要素的情绪读数，替换掉打架的那个 |

## 用户字段纪律

用户给了字段模板或 `【...】` 标题时，严格保留：只输出那些标题、保持名称 / 标点 / 顺序、不增删重排字段；只可优化字段内措辞。没给模板时才用下面的 fallback 结构。

用户的锁定模板（当用户提供时）：

```text
【镜头角度】【镜头尺寸】【景别】【景深】
【主体一——...】【核心身份/物种】【体型/外貌特征】【材质/纹理】【动作/姿态】
【主体二——...】【核心身份】【体型/外貌特征】【材质/纹理/服饰】【动作/姿态】
【核心机位位置】【天气与氛围】【前景】【中景】【远景】【背景】
【主光源/方向】【光线软硬质感】【辅光源/互动光】【特效光/气氛光】
【整体色温/基调】【色彩饱和体系】【高光与阴影倾向】【对比度与饱和度】
```

## Fallback 结构（仅当用户没给字段）

视觉意图/情绪目标 → 观众位置/权力关系 → 镜头角度/焦距 → 画幅 → 景别/构图 → 空间心理 → 景深/叙事焦点 → 主体(身份/外貌/材质/动作) → 环境(前/中/远/背景) → 光(主光/软硬/辅光/气氛光) → 色(色温/饱和/高光阴影/对比) → 电影机/胶片质感 → 去噪/干净强调 → 负面约束。

## 负面约束（只选相关的）

不要鲜艳高饱和色；不要干净棚拍光；不要明显 CG 体积光束；不要塑料光泽 / 玩具感表面；不要卡通 / 动漫风(除非要求)；不要文字 / logo / 水印；不要多余肢体 / 畸变脸 / 重复人物；不要前景物挡住主体；不要杂乱噪点 / 过度锐化 / AI 塑料感。

## 输出格式

除非用户另有要求：

1. **🔍 分析**：2–5 条短句，说明抽取的故事、光、构图、色、质感选择（每条点出为什么服务情绪）。
2. **✏️ 提示词**：可整段复制的最终提示词，中文或双语跟随用户语言。这是主体。
3. **🚫 避免**：一行简洁负面/去 AI 感清单。
4. **（可选）2–3 个变体**：布光或构图**明显不同**，不是同义词替换。
