# 模块: live-action-texture（professional-cinematic-image 子模块，按需加载）

### 真人实拍质感（解决'AI 味/塑料感'的根因——真实照片来自光学缺陷，不是完美）

- **为什么出不了实拍感**：AI 默认生成'概念完美图'——塑料皮肤/色彩均匀/光影干净/全动态范围/构图工整，这些恰恰是真实照片里不存在的东西；实拍感 = 具体光学系统的缺陷总和（颗粒/暗角/色差/有限宽容度/不完美构图）。提示词必须回答'这是哪台相机+哪支镜头+哪卷胶片/哪档 ISO 拍的'
- **胶片系统指定（选一种写进提示词，颗粒与色彩响应随之而来）**：Kodak Vision3 250D（日光片：细腻颗粒/暖中性肤色/高宽容度——主流故事片）· Kodak Vision3 500T（钨丝灯片：粗颗粒/橙-青分离/夜景质感）· Fuji Eterna 500（冷调肤色/细腻）· 黑白 Tri-X 400（粗颗粒/高反差/纪实）；'电影感'三字永远不够——必须具体到胶片型号
- **镜头光学指定（镜头的缺陷就是质感）**：球面定焦（Cooke S4 类：奶油般焦外/柔和高光/轻微低反差——人物首选）；变形宽银幕 Anamorphic（椭圆光斑/水平蓝色光晕/垂直拉伸光带/焦外菱形——史诗/追忆感）；老式镜头（暗角/紫边/低反差/呼吸感——年代/粗糙感）；镜头词写法：'Cooke 风格球面镜头，奶油焦外，柔和高光'或'变形宽银幕镜头，椭圆眩光'
- **光学缺陷正面描述（这些是'真实照片的证据'，写进提示词而非负面清单）**：轻微暗角（四角渐暗）· 高反差边缘色差紫边 · 特定角度镜头眩光（单点光斑）· 焦外洋葱圈/旋焦 · 胶片颗粒随暗部变粗（阴影颗粒 > 高光颗粒）· 高光软溢出（不是死白是渐变）· 白平衡不完美（整体微偏色是真实的）
- **暗部分层纪律（关键修正：实拍≠死黑，黑而有层次才是电影感）**：真实电影的暗部是'深灰渐变保留隐约细节'（黑而不死），死黑只允许出现在光源背面/画面角落/最深处，且占画面 ≤10%；提示词写法——'暗部深灰保留层次，仅光源背面与角落有少量死黑'，禁止写'暗部死黑/大面积死黑/暗部细节压缩'这类让整体变黑的词；主体永远保持中间调（暗部层次再深，主体亮度必须可辨）
- **实拍曝光逻辑（提示词写'曝光行为'而非'亮度'）**：高光溢出只给光源本身（灯/窗外）不给皮肤；暗部写'深灰层次'而非'死黑'（死黑限量 ≤10% 且只给角落）；动态范围有限=中间调优先（'主体中间调清晰，高光溢出与角落死黑并存'——不是全画面压暗）；运动模糊按快门角度（1/48s 的拖影）；对焦不完美（焦平面偏移/边缘柔和）
- **不完美原则（构图与状态）**：真实照片的随意性——切头/前景遮挡/主体不在正中心/背景杂乱/人物表情不完美/眨眼瞬间/衣褶自然堆叠；AI 的'完美构图+完美表情+完美光线'正是出戏根源；负面清单加'无完美对称/无影棚净光/无人物摆拍感/无过度磨皮'
- **数字摄影机替代（不用胶片时）**：ARRI Alexa 风格（大宽容度/肤色过渡细腻/暗部干净）；RED 风格（锐利/细节多）；索尼 FX 风格（现代肤色/视频感稍强）；'35mm 胶片扫描质感'默认已含——需要更具体时按本条指定机身
- **实拍质感自查（出图前）**：① 胶片/机身指定了？② 镜头指定了？③ 至少 2 个光学缺陷正面描述了？④ 曝光行为写了（溢出/死黑/宽容度）？⑤ 构图有'不完美'元素？⑥ 负面清单有塑料/磨皮/摆拍？六项全过才出图

### 实拍证据层（提示词做到'像真照片'的最后一步——具体到光学行为/胶片响应/现场物理/后期痕迹）

- **为什么还不够像实拍**：'电影感+胶片+镜头'仍可能出 AI 图——因为缺'证据'：真实照片是光、镜片、化学/传感器、现场尘埃、后期工艺共同作用的物理结果；提示词要写出这些'作用过程'，AI 才模仿得出
- **镜头光学行为（比'奶油焦外'更具体的镜头证据）**：焦外形状（圆形光斑=球面镜/椭圆形=变形镜/旋焦=老双高斯结构）· 光斑内部结构（洋葱圈=非球面镜片打磨痕迹/同心环=镀膜干涉）· 色散行为（高反差边缘紫边/绿边——位置固定，不是全图均匀）· 呼吸效应（对焦时画面轻微缩放——写'焦点处边缘轻微呼吸'）· 锐度曲线（中心锐利边缘柔和=大光圈特性/全图均匀=小光圈）· 暗角形状（四角渐暗或'光斑状暗角'=老镜头特性）
- **胶片/传感器响应（比'颗粒'更具体的介质证据）**：胶片——高光肩部曲线（亮部柔和压缩不是死白）、阴影趾部（暗部颗粒堆积带色偏：500T 阴影偏青绿）、颗粒的色度分布（暗部颗粒带色/亮部颗粒中性）、片基密度（黑位微灰不纯黑）；数字机——暗部噪点的颜色（高 ISO 暗部噪点偏品红/绿）、传感器辉光（高光边缘的紫红色溢出）、滚动快门/果冻效应（快速运动边缘倾斜）
- **现场物理证据（证明'真的拍过'的痕迹）**：镜头前灰尘（特定光源下的光斑点/灰圈——'光源处有一枚圆形灰斑'）· 传感器污点（固定位置的暗斑）· 轻微跑焦（主体边缘微微发虚/焦点落在睫毛不在眼睛）· 手持微晃（0.5mm 级位移的轻微拖影——静帧里体现为边缘微糊）· 快门拖影（运动物体 1/48s 的拖尾）· 镜头起雾（潮湿环境下的雾气蒙层——'画面边缘有轻微雾气蒙层'）· 滤镜痕迹（ND 镜的轻微偏色/黑柔滤镜的暗部软化）
- **光线物理（真实光源的行为）**：多色温混光（钨丝灯 3200K+窗外月光 6500K+远处钠灯 2200K 同时在场——各自照到不同区域，不是均匀调色）· 光的衰减（平方反比：近处亮远处暗，不是均匀布光）· 体积光密度（丁达尔光束里能看见尘埃颗粒，光柱边缘柔化）· 反射的真实（高光反射带色：酒液反射带琥珀色，水面反射带天色）
- **后期/工艺痕迹（最后一个证据层）**：印片光/冲印痕迹（胶片扫描的划痕/静电痕/接缝线——轻微、不抢画面）· 调色痕迹（不是均匀调色：高光偏暖暗部偏冷的局部色温分离）· 颗粒与锐化的关系（去噪不足的边缘颗粒感）· 黑位处理（抬黑=数字感/压黑=胶片感——按介质选择）
- **证据层纪律**：证据要'轻微且局部'（3-5 处即可，写满会脏）· 证据要'有位置'（'光源右上角一枚灰斑''右脸边缘微跑焦'——写位置才真实）· 证据要'与介质匹配'（胶片机写胶片证据，数字机写传感器证据，禁止混写）· 每张图至少 3 类证据（光学行为+介质响应+现场物理）
