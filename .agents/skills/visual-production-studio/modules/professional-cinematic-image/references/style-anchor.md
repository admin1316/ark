# 模块: style-anchor（professional-cinematic-image 子模块，按需加载）

### 画风锚定（AI 生图"像不像一回事"的第一决定因素——提示词必须锁定具体风格，禁止只写"电影感/写实"这类空泛词）

## 为什么画风必须锚定

同一场景描述，画风不锁 = 模型自由发挥 = 每张图风格漂移（一张动画感、一张半写实、一张 CG 感）。AI 出图"不像"的第一根因不是细节不够，是风格参照没给。顶级提示词的画风层 = 让模型知道"这是谁的片子/哪部电影的截图/什么胶片/什么色板/什么质感"。

## 五维风格锚定（生图提示词必带，按此五维写）

1. **艺术家/导演参照（最强的锚）**：选 1 位风格最贴合的导演/摄影师/画家写进提示词——"张艺谋式史诗色彩"（浓烈对称）、"侯孝贤式长镜静谧"（写实克制）、"维伦纽瓦式科幻庄严"（冷峻大尺度）、"李安式东方美学"（温润含蓄）、"王家卫式霓虹情绪"（高饱和暧昧）、"罗杰·狄金斯式光影"（自然光大师）、"库布里克式对称"（几何强迫症）；规则：只选 1 位（多选互相打架），必须写"式"字表明是风格借鉴非本人
2. **电影/胶片参照（锁定色调与质感）**：写具体胶片或电影色调——"Kodak Portra 160 肤色柔和"（人像）、"Kodak Vision3 250D 电影卷"（电影感）、"Fuji 胶片冷绿"、"35mm 胶片颗粒"、"IMAX 质感"；或写电影名——"《影》的水墨黑白"、"《卧虎藏龙》的竹海青绿"、"《妖猫传》的盛唐金红"
3. **色板锚定（锁定色彩关系）**：写主色/辅色/强调色的具体关系——"主调冷青灰占 70%，暖金占 25%，桃花粉为唯一强调色占 5%"；或写色彩体系——"低饱和莫兰迪"、"高饱和撞色"、"单色+一点强调色"、"青橙互补"
4. **质感锚定（锁定表面处理）**：写材质的物理感——"胶片颗粒+轻微暗角"（复古）、"哑光油画布纹"（艺术）、"超写实皮肤毛孔"（人像）、"水墨晕染边缘"（东方）、"金属冷光反射"（科幻）；明确要"照片感"还是"绘画感"还是"CG 感"
5. **光影风格锚定（锁定光的性格）**：写光的语言——"伦勃朗光（三角光区）"、"蝴蝶光（鼻下蝶影）"、"侧顶 45° 电影主光"、"低照度烛光"、"高调柔光（无阴影）"、"剪影逆光"；光的风格 = 电影的情绪签名

## 画风锚定写法模板（直接套用）

`风格：<导演/艺术家>式<题材> + <胶片/电影>质感 + <色板> + <质感词> + <光语言>。参考：<电影名或具体参照>。`

示例：`风格：张艺谋式史诗神庭 + Kodak Vision3 电影卷质感 + 冷青灰主调暖金强调 + 胶片颗粒轻微暗角 + 伦勃朗侧光。参考：《英雄》的色彩仪式感。`

## 画风自检（出图前逐项过）

① 有没有 1 位导演/艺术家参照？（没有=必加）② 有没有胶片/电影色调？（没有=必加）③ 色板是否具体到百分比或体系名？④ 质感是否明确（照片/绘画/CG/水墨）？⑤ 光语言是否明确？⑥ 是否只选 1 位导演（没打架）？六项全过再出图。

## 失败模式对照

- 只写"电影感/史诗感/高级感" = 零锚定 = 模型自由发挥（最差）
- 写 3 个以上导演 = 风格打架 = 出四不像
- 有导演无胶片无色板 = 只有一半锚，色调仍漂
- 负面词里有"卡通/3D"但正面没有风格 = 只防不立，画面仍飘


## 风格库联动（300+ 现成风格词）

需要具体风格词时读取影视工作室内部的 [电影风格库](../../../../cinematic-production-studio/modules/cinematic-prompt/references/movie-styles.md)（300+ 条，按类别取用）：
- 影视风格 60 条（王家卫式慢镜头+饱和色彩/黑泽明式高反差黑白/张艺谋式红绿对撞对称/李安式自然光内敛/诺兰式暗色调等）
- 画面质感 60 条（胶片颗粒/水墨晕染/哑光油画/赛博发光等）
- 灯光色调 60 条（伦勃朗/蝴蝶光/霓虹/烛光/高调柔光等）
- 摄影手法 60 条（手持/航拍/长焦压缩/微距/移轴等）
- 平台风格 60 条（抖音竖屏/电影宽屏/复古胶片/国风等）

用法：先定"导演参照"再从此库取 2-3 个匹配词组装成完整风格句；禁止堆砌（一条风格句最多 3 个风格词）。
