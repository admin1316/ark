# 模块: color-grading（professional-cinematic-image 子模块，按需加载）

### 电影调色方案（色彩分级四型 + 色板控制，写提示词前先定调色）

- **调色四型（按情绪基调先选型，再写提示词）**：① 青橙互补（Teal-Orange）——暗部青蓝+亮部暖橙，商业大片标准型，适用对抗/爽感/都市夜；② 单色调（Monochrome）——去饱和到近单色（蓝灰/棕褐/墨绿），适用压抑/历史/悬疑，情绪最重；③ 低饱和暖调——整体偏暖但压饱和度（黄昏/回忆/温情），适用情感戏；④ 高调/低调（High-key/Low-key）——高调明亮少阴影（清新/梦境），低调大阴影区（惊悚/黑帮）
- **色板纪律（提示词给 2-3 个明确色，不堆色名）**：主色（环境基调色，如'冷青夜色'）· 强调色（唯一暖色，如'暖钨丝灯/眉心暗红印记'——全画面只此一处）· 辅助色（皮肤/道具固有色）；写'克制低饱和/褪色泥土调/琥珀阴影'类方向词，不写'色彩丰富/五颜六色'
- **肤色纪律（人脸镜优先）**：肤色是画面最敏感色板——暖主光下肤色保持自然（不偏绿不偏橙）；冷调环境用'肤色仍保持暖调'对冲（人脸永远最暖）；负面提示加'无肤色发绿/发灰/塑料肤'
- **情绪色逻辑（色随情绪变）**：情绪升级时强调色面积增大或饱和度升高（危机逼近=暖色越来越刺眼）；情绪压抑时整体饱和度下降（崩溃前的画面先失去颜色）；回忆/闪回=整体偏黄+柔边；危险信号=冷调中唯一暖色（见光色纪律）
- **系列/多格一致（衔接海报系列一致性）**：同一作品的关键帧/海报共用同一调色方案（主色+强调色+方向词固定）；切换情绪场次时只调整强调色饱和度，不动主色；负面提示固定'无高饱和/无青橙割裂/无塑料感'
- **调色自查（出图前）**：① 调色四型选了哪个？② 主色/强调色/辅助色各是什么？③ 唯一暖色是否明确？④ 肤色是否保持暖调？⑤ 情绪色逻辑是否成立？⑥ 与同作品其他图调色一致？
