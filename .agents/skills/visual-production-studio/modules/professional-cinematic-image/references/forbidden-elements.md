# 模块: forbidden-elements（professional-cinematic-image 子模块，按需加载）

### 禁入元素纪律（单张关键帧防"跨场景/跨章节道具污染"——AI 会把别的镜头的元素画进来）

## 问题根源

AI 生图模型（尤其对话式，如 ChatGPT 内的 gpt-image）**会受会话历史污染**：如果之前生成过后续章节（发光杯、香炉、巨钟），新图就会把那些道具"移植"进来。实测案例：第一章「称光」的船头，模型画出了第二章的"引香酒杯"、把"坐姿持桨"画成"站立持杯"。提示词只说"要什么"，没说"不要什么"——模型就自由发挥。

## 纪律（单张关键帧必做）

1. **写"本帧禁入"清单**：生成前先列出本帧**绝不允许出现**的元素——来自其他章节的道具、其他镜头的标志物、与场景矛盾的物品。写法：负面清单加 `绝对禁止出现：<元素1>、<元素2>……`（中文提示词）；英文提示词加 `absolutely no: <element1>, <element2>`
2. **写"本帧必须"清单**：与禁入清单对称——本帧的标志性道具必须出现。写法：`必须出现：<道具>，<状态>（<位置>）`。例：`必须出现：乌木桨斜握在人物右手中，桨叶拖过水面推开花瓣`
3. **跨章节防污染（系列图必做）**：同一作品连续出多张图时，每张图的禁入清单必须包含**其他章节的标志道具**——第一章禁：酒杯/香炉/锈钟/白衣仙女；第二章禁：木船/桃花瓣/金柱；以此类推。防污染清单从作品的符号锁资产表（CH/PR/EN/LG 编码）推导
4. **人物姿态锚定**：关键帧的人物姿态必须写死并进负面——"人物坐姿（非站立）""手持木桨（非其他物品）"；负面加 `无站立、无手持酒杯/发光物`
5. **出图后核查**：按本帧"必须/禁入"清单逐项对照生成图（视觉模型核查），任一禁入元素出现=重出；任一必须元素缺失=重出

## 模板（直接套用）

```
【本帧必须】<道具1>（<状态>，<位置>）；<道具2>（<状态>，<位置>）；人物<姿态>
【本帧禁入】绝对禁止出现：<其他章节道具1>、<其他章节道具2>、<矛盾物品>；无<错误姿态>
```

示例：
```
【本帧必须】乌木桨斜握右手，桨叶拖过水面推开花瓣；人物坐姿在船中，双眼紧闭
【本帧禁入】绝对禁止出现：酒杯、香炉、锈钟、白衣仙女、发光杯盏；无站立、无手持发光物
```

## 自检

① 本帧标志道具写了"必须出现"？② 其他章节道具写了"禁入"？③ 人物姿态写死并进负面？④ 出图后按清单核查过？——四项全过才交付。
