# 电影感配方库

可直接取用的布光 / 构图 / 色彩配方、提示词碎片，以及"出图不对劲"的对症修法。整理自优秀电影截图（movie-still）参考的共性规律。

## 优秀电影截图的共性

- **可控的暗**：很多画面边缘欠曝，脸或手势只微微从阴影里分离出来。
- **有动机的光**：窗光、灯、电视、霓虹、火、车灯、门缝光——照明看起来"有来源"。
- **选择性清晰**：只有几个重要平面是清楚的，前景/背景/烟/玻璃/运动把其余柔化。
- **有限色盘**：暖实用光对冷环境光，或克制的绿/琥珀/蓝/棕，而非全光谱高饱和。
- **大气纵深**：雾、尘、雨、脏玻璃、薄霭、窗帘、百叶、反射，制造层次。
- **叙事性框取**：画面暗示"前一刻/后一刻"——人物正在行动/等待/躲藏/聆听/离开/察觉。
- **不完美的照相质感**：颗粒、halation、抬高的黑位、柔对比、泛光、暗角、轻微畸变，削弱数字洁净感。

## 布光配方

- **低调室内**：单个实用台灯，房间大半在阴影，暖光落在手或脸，背景冷窗光补光。
- **窗光光轴**：硬角度阳光穿过百叶/窗帘，可见尘埃/薄雾，主体被光切开一部分。
- **夜景外景**：钠灯街灯，湿路面反光，深负空间，小片色光。
- **荧光不安**：绿蓝顶光，肤色略去饱和，阴影发浊而非纯黑。
- **黄昏忧郁**：蓝色环境曝光，窗/车灯/落日一抹暖边缘光。
- **逆光剪影**：主体靠轮廓与姿态可辨，脸大半隐藏，背景比前景亮。
- **屏幕微光**：电视/手机的青光塑造脸部，四周暖暗，浅景深。

## 构图配方

- **门框框取**：主体透过门/走廊被看见，压缩、被观察。
- **前景遮挡**：越过窗帘/玻璃/肩膀/植物/车窗/货架/雨拍摄。
- **负空间**：主体放在角落或下三分之一，让环境承载情绪。
- **桌面调度**：手、物、实用光形成注意力三角。
- **反射**：镜子/窗/水洼/车窗/抛光面，复制主体或藏起信息。
- **广角孤独**：小小人形对着建筑/风景/空房间。
- **近景碎片**：裁到眼/手/嘴/烟/钥匙/物件，故事靠语境暗示。

## 色彩配方

- **暖实用光 / 冷环境光**：琥珀灯、蓝窗影、克制肤色。
- **钠灯夜**：琥珀街灯、绿黑阴影、湿暗中性色。
- **褪色日光**：低饱和、柔对比、苍白天空、轻颗粒。
- **荧光绿**：病态青绿铺底 + 一点暖红/琥珀点缀。
- **尘金**：晚阳、棕木、米墙、烟草色阴影、克制高光。
- **银蓝**：阴天、雾、水、混凝土、低暖度。

## 提示词碎片（可直接拼进正向提示词）

- `dim practical light from a single table lamp`（单台灯的昏暗实用光）
- `soft halation around the window highlights`（窗高光柔 halation）
- `shadow detail preserved but not fully clear`（阴影有细节但不完全清晰）
- `muted film color grade, restrained saturation`（褪色胶片调、克制饱和）
- `foreground blur through dirty glass`（透过脏玻璃的前景虚化）
- `haze catching a narrow beam of light`（薄雾接住一道窄光束）
- `underexposed corners with readable silhouettes`（欠曝的角落 + 可辨剪影）
- `35mm film still texture, fine grain, lifted blacks`（35mm 胶片截图质感、细颗粒、抬高黑位）
- `clean and low-noise, natural skin texture, not glossy`（干净低噪、自然肤质、不油亮）
- `not a poster, not a studio render, not glossy`（不是海报/影棚渲染/油亮）

## 常见修法（出图不对劲时对症下药）

- **太亮**：要欠曝的边缘、只用实用光、去掉全局补光、阴影占半幅。
- **太清晰/太平**：加前景遮挡、浅景深、薄雾、运动柔化，或轻颗粒。
- **太饱和**：指定克制色盘、两色家族、褪色印刷、克制调色。
- **太普通/太 AI**：加一个故事节点、物件线索、明确时间、有动机的光源。
- **太脏 / 太多噪点（Image 2 常见）**：强调 `clean, low noise, no artifacts, natural fine grain only`；**去掉** `8k / ultra detailed / hyper sharp`；只保留"细腻自然颗粒"，不要重度做旧、不要"gritty/heavy grain"堆叠。
- **太塑料 / 太 AI 抛光**：去掉 `perfect / masterpiece / flawless`，加不完美镜头对比、halation、自然肤质与轻噪。

## 核心信条

- 宁要"有可读意图的暗"，也不要"全清晰"——让一部分画面落进阴影。
- 让光"来自场景里的某个东西"（灯/窗/电视/街牌/烛/车灯/手机/斜阳）。
- 色彩守纪律：两三个色家族 + 污染与衰减，而非彩虹高饱和。
- 把不完美当手艺，但**克制**——薄雾、颗粒、halation 点到为止，别堆成脏噪。
- 像摄影师那样思考，而不是像相机参数表——镜头/胶片术语服务画面，别喧宾夺主。
