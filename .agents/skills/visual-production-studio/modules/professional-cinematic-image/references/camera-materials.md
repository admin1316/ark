# 模块: camera-materials（professional-cinematic-image 子模块，按需加载）

### 物理相机与材质物理层（单帧关键帧/海报/概念图的渲染规格，与视频侧共用同一套纪律）

- **ShotDeck 检索词输出（提示词交付时附带）**：每张关键帧/海报提示词末尾附一行检索串（来自 [情绪→行业词映射速查](../../_shared/emotion-shot-matrix.md)），如 `ShotDeck: Rembrandt + MCU + 85mm + Warm + Window Light`——用户可直接去参考库找同款参考图对照出图效果

- **行业灯光语言（来自 [ShotDeck 级行业词库](../../_shared/shotdeck-standard-language.md)，写提示词光段直接用行业术语）**：风格（High Key/Low Key/Chiaroscuro/Rembrandt 伦勃朗光/Butterfly 蝴蝶光）· 方向（Front/Side/Side-top 45°/Top/Underlighting/Backlit/Rim）· 光源（Practical 实用光源/Window 窗光/Slit Light 门缝光/Neon/Candlelight/Screen Light）· 特殊（Silhouette/Semi-Silhouette/Volumetric 丁达尔）——例：'Rembrandt lighting, practical window light, warm' 比 '柔和侧光' 精确一个行业层级；与 ShotDeck 参考图对照时用 'Lighting: Low Key + Backlit' 式组合

- **物理相机参数化（提示词里写死，不写'或'）**：焦距（35mm 中性/50mm 肖像/85mm 特写压缩/24mm 大场面/100mm 细节微距）+ T 光圈（浅景深 T1.4-2 特写/T2.8 双人/T4 环境）+ 快门/ISO 感光度取向（低 ISO 干净/高 ISO 颗粒为情绪服务）+ 白平衡/色温（暖金 3200K 或冷青 6500K，单一主基调）+ 曝光补偿方向（-0.3EV 保暗部/+0.3EV 高调）——五个变量每个只选一个，全部进提示词
- **主光保底（人脸生死线）**：人脸永远给足主光——侧顶光 45° 暖金主光清晰照亮左脸（五官可辨）+ 发丝边缘一线金边轮廓光；禁止强逆光人脸（关键帧生成对逆光人脸极不稳定，糊成剪影或五官崩坏）；微表情/神态描写给最小集（眉头/嘴角/眼神方向），不写抽搐级表情
- **材质物理层（真实质感的来源，写进提示词的材质词）**：皮肤 = 自然肤质+次表面透光感（'皮肤下透出血管色/耳廓透光'）；布料 = 具体织物微表面（亚麻粗糙/丝绸高光/皮革粒面）；金属 = IOR 反射明确（旧铜露铜/不锈钢冷反光）；水面/玻璃 = 折射与倒影；避免'塑料光泽/玩具质感/过度做旧'
- **主体类型适配（人和物标准不同——写材质与负面前先定主体类型）**：① **真人**——皮肤走 SSS/毛孔/微表情，负面含'无塑料皮肤/无恐怖谷/无过度磨皮'；② **神像/雕塑/金身**——材质按设定写（鎏金漆面/彩绘/泥塑/石质），'光滑漆面'是合理材质不是缺陷，负面**不写**'无塑料感'（改写'无廉价玩具感/无塑料玩具光泽/无3D模型感'），并写'雕塑工艺感：鎏金均匀/彩绘精细/磨损做旧自然'；③ **道具/食物**——按各自材质层（木质包浆/金属氧化/食物油脂果霜），负面按类选；④ **动物**——毛发/解剖/眼神。规则：**'塑料感'类负面只用于真人/生物，神像和道具用'材质是否符合设定'判定**
- **单主体单焦点（一镜一事的静态版）**：一张图只讲一件事、只有一个视觉焦点（特写主体的高光点/裂缝液滴/眼神光）；信息超过一个焦点 = 拆图；氛围元素（光尘/花瓣）宁少勿多，密度以不抢主体为准
- **与分镜的衔接**：输入 = director-master 分镜表扩展字段（管线/物理相机/出点帧/转场）+ visual-storyboard-master 画格描述；输出 = 海报/关键帧/概念图，供成片质检对照


### 主体坐标规划纪律（生图提示词必带——AI 生图"人物位置失控"的根治方案）

- **每个关键主体给归一化坐标**（画面左=0 右=1 上=0 下=1）：主主体写精确交点（如"主体位于 x=0.382、y=0.4，头在 40% 高度、脚在 72% 高度"），次主体写相对位置（"反派在 x=0.2 面向主角"），远景群众只写区域（"左上 1/4 剪影"）
- **一图一主锚点**：先写观众第一眼落点（眼/手/关键物）的精确位置，再写次锚点与视线路径；禁止让两个重要主体同框同区域争焦点
- **景深三层必写**：前景层（边缘 10-15% 遮挡/道具）+ 中景层（主体 40-60%）+ 后景层（环境/人群/天穹 30-40%），每层写明内容与虚化程度
- **安全区**：眼/脸/手/关键物必须在 x=0.05-0.95、y=0.08-0.92 内，禁止贴边出画（AI 常把人脸切到边缘）
- **多人场景**：每个重要人物坐标分开写，人物脚底同一地平面，次要人物压缩为剪影；负面加"无人物堆叠/无主体过小/无贴边裁切"
- **失败自查（出图后）**：① 第一焦点 1 秒内可辨？② 主体在预定坐标 ±10%？③ 眼/手无意外裁切？④ 人物无堆叠无重叠？⑤ 去色后构图仍成立？任一不过=重画
