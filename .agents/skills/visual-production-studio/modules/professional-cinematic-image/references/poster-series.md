# 模块: poster-series（professional-cinematic-image 子模块，按需加载）

### 海报版式与系列一致性（电影海报/短剧封面/系列物料，标题位与构图纪律）

- **版式三区**：视觉焦点区（上 2/3——主体/关键帧/表情特写，是观众第一眼落点）· 标题区（下 1/3 或顶部——留出干净负空间放片名/文案，提示词写'画面下方预留标题负空间'或'上方留黑'）· 信息区（小字位：导演/主演/档期——生成后由排版层添加，提示词不生成文字）
- **单角色海报**：主体占画面 50-65%，视线方向引导标题（人物看向标题区=视线闭环）；经典三式——正面特写（情绪冲击）、侧面剪影（神秘悬念）、背影+回眸（关系张力）；背景是情绪延伸（雨夜/光尘/废墟）不是装饰
- **双人海报**：位置关系=人物关系（并肩=同盟/对峙分列=对抗/一高一低=权力差）；两人视线：互看=亲密/同看一方=共敌/各看一边=离心；间距与画幅边缘留白制造张力；忌两人同侧同姿势（复制感）
- **群像海报**：三角构图（主角居中顶部，次角两侧递进，背景角压底边）；主次用大小/前后/光量区分（主角最大最亮，配角递减）；脸部朝向多角度（全朝同一方向=呆板）
- **系列一致性（多集/多张物料必须统一）**：固定四项不变——主色调（每张同基调色板）、字体区域（标题位恒定）、主角锚点（脸/发型/标志物逐张一致）、光影语言（同光源方向）；系列变化项：情绪/场景/构图变体；输出系列时先出'母版'再逐张变体，母版锁定四项常量
- **文字纪律**：提示词不生成任何文字/标题/logo（生成后排版层加）；负面提示加'无文字/无水印/无标题'；'海报式对比'是反 AI 感的负面词，但'电影海报质感'作为风格词可保留
