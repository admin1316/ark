# 情绪 → 视觉决策表 ＋ 摄影要素 → 情绪 反查

两个方向都能用：
- **正查**：先定情绪，据「情绪→视觉决策表」选机位/焦段/构图/光色。
- **反查**：已定某个机位/焦段/光色，据「反查速查表」确认它传达的情绪是否对味。

## 一、情绪 → 视觉决策表（Quill 原表，原样保留）

| 情绪 | 机位 / 焦段 | 构图 / 空间 | 光 / 色 |
|---|---|---|---|
| 恐惧 / 压迫 / 被支配 | 低机位、轻微仰拍；长焦 / 超长焦压缩 | 威胁占主导体量；人作尺度参照；删逃生路线 | 侧逆光穿尘 / 雾；低饱和冷调 |

| 敬畏 / 神话 / 宗教 | 低机位、正面对称、仪式调度 | 小人物 + 纪念碑主体；垂直 / 圆形支配 | 真实大气逆光光晕；克制金 / 石 / 骨色 |
| 幽闭 / 无路 | 长焦压平、或紧广角近景畸变 | 删天空地平线；雾 / 墙 / 烟封闭画面；藏出口 | 低亮度；出口方向无光 |
| 孤独 / 遗弃 | 远距、静态、旁观 | 大量负空间；人偏离中心且小 | 冷灰 / 褪蓝 / 弱光；环境压过人 |
| 权力 / 权威 | 仰拍(支配) 或 眼平对称(制度) | 居中、对称、垂直、王座轴；压缩柱列 / 人群 | 硬侧光、受控阴影；深暗限制色盘 |
| 追逐 / 恐慌 | 手持、肩高、跟拍背影、低跑视角 | 倾斜线、局部遮挡、前景虚化、破碎构图 | 实用光、雨中反射、强对比、爆高光 |
| 亲密 / 脆弱 | 近距眼平 / 过肩；标准到短长焦 | 脸、手、呼吸距离、小动作、可触表面 | 浅焦锁眼 / 手；暖肤、柔对比 |
| 冷感 / 无生命 | —— | —— | 低饱和；铁 / 骨 / 灰烬色盘；哑光、矿物、冰冻材质 |
| 纪录片灾难真实 | 物理可信曝光，非 CG 光 | 真实大气：尘捉逆光、雨散街灯、烟吞对比、雪压距离 | 不做 CG 光束；克制颗粒、局部泛光 |

镜头速记：低机位＝权力上移(弱势 / 压迫)；高机位＝脆弱 / 被监视；眼平＝纪实在场；广角＝逼近 / 畸变 / 恐慌；长焦＝压缩纵深 / 不可逃避；浅景深＝锁叙事焦点；深焦＝关系全可读。

## 三、摄影要素 → 情绪 反查速查表

> 依据：Bruce Block《The Visual Story》、Roy Thompson《Grammar of the Shot》、Mascelli《五C》、Sikov、Bellantoni《If It's Purple, Someone's Gonna Die》等。多为强惯例，但都存在语境例外——反用时确认动机。

### 机位与角度

| 要素 | 情绪/功能 | 一句话机制 |
|---|---|---|
| 眼平机位(eye-level) | 中立/平等/客观/日常代入 | 视线与被摄者持平、同一权力高度，叙事的零度基准 |
| 低机位仰拍(low angle) | 力量/支配/威严/英雄；反面压迫威胁 | 被摄者高于视线并占上方，迫观众抬头仰望生臣服 |
| 极端低机位/虫视/贴地 | 压倒性巨大/纪念碑崇高；亦荒诞或英雄登场 | 极端向上透视令垂直线汇聚、体量被夸张放大 |
| 高机位俯拍(high angle) | 脆弱/弱小/被压制/被审视 | 观众俯视，角色被压在下方、权力被剥夺显渺小 |
| 轻微俯角/美颜角度 | 柔化/讨喜/亲和/显脸小 | 略高于眼使眼上扬、下颌收窄，五官上镜且无威胁 |
| 顶视/上帝视角/鸟瞰 | 宿命/全知/人如棋子；或图案美与秩序 | 完全脱离人物视线的垂直俯瞰，角色沦为几何单元 |
| 航拍/大俯建置 | 宏大/史诗/孤立/抽离 | 极大高度拉开人与环境比例，强调规模、地理与孤独 |
| 荷兰角/倾斜机位 | 不安/失衡/眩晕/疯狂/危险 | 倾斜地平线违背前庭平衡直觉，身体本能感到不对劲 |
| 主观镜头/POV | 代入/认同/沉浸；反派 POV 则被窥视共犯 | 相机即角色的眼睛，强制共情或强制共谋 |
| 过肩镜头(OTS) | 关系连接/对峙或亲密的空间锚定 | 前景肩背把双方纳入同一空间，建立视线轴与在场关系 |
| 客观/第三人称机位 | 旁观/疏离/冷静记录/不介入 | 相机不归属任何视点，观众是墙上的苍蝇 |
| 髋/腰部机位 | 一触即发张力(西部拔枪)/儿童视角 | 视点降到腰髋高度，露出枪套或还原孩童身高 |
| 榻榻米机位/低坐姿眼平 | 静谧/平等/日常亲密/谦卑庄重 | 降到跪坐者眼高并严格保持水平，是「低位眼平」而非俯仰 |
| 正面直视/打破第四面墙 | 直接对峙/审问式亲密/共谋或坦白 | 角色正对镜头四目相对，把观众拉成对话对象 |

### 焦段与镜头

| 要素 | 情绪/功能 | 一句话机制 |
|---|---|---|
| 超广角/鱼眼(8–18mm) | 迷失/癫狂/眩晕/超现实；风光则壮阔渺小 | 极端透视拉伸+边缘弯曲脱离人眼经验 |
| 广角(24–35mm) | 开阔/临场/能量/纳入人物与环境关系 | 视角宽、纵深夸张、景深大，把观众拉进空间 |
| 广角贴脸大特写 | 压迫/攻击性/荒诞/侵入式不适 | 极近摄距放大鼻额成怪相、侵入私密距离(变形本质来自摄距) |
| 标准镜头(50mm) | 中性/自然/客观/写实 | 透视压缩最近人眼，空间诚实、情绪最弱退让给内容 |
| 85mm 人像中焦 | 亲密/优美/体面 | 轻度压缩美化面部+适度背景分离，把人温柔抽离 |
| 中长焦(100–135mm) | 观察/窥视/抽离旁观/被压缩的宿命 | 空间压缩+浅景深把主体从背景剥离，像远远注视 |
| 超长焦(200mm+) | 极致压缩/人群窒息/困于其中/冷眼疏离 | 极端压缩把纵深叠成一片，再运动也拉不开背景 |
| 微距(macro) | 陌生化/触感质感/隐秘张力/科学冷冽 | 把肉眼略过的细节放大到充满画面，逼人看得太近 |
| 浅景深/大光圈 | 梦幻/浪漫/主观/记忆；或注意力指挥棒 | 只留一层清晰、虚化其余，替观众剔除干扰 |
| 深景深/深焦 | 客观/信息密度高/前后景并置张力/写实 | 全画面皆实、不替观众选看点，近远景同时叙事 |
| 广角畸变(主动手法) | 醉态/癫狂主观/不安/荒诞失衡 | 直线弯曲、比例失真，把正常世界扭成心理异常者所见 |
| 长焦压缩(主动手法) | 宿命/被困无处可逃/拥挤/被推着走 | 前后距离被压平，人物前进也拉不开背景，空间不给出口 |
| Dolly zoom 变焦推拉 | 眩晕/恐惧/顿悟/世界崩塌 | 推轨与变焦反向，主体不变而背景透视骤变、空间失真 |
| Rack focus 移焦 | 注意力牵引/揭示/两平面对峙 | 焦点在前后景迁移，改写视线落点与叙事重心 |
| 变形宽银幕(anamorphic) | 史诗/宏大/电影感/怀旧大银幕 | 椭圆焦外+水平蓝炫光+更宽视野=「这是电影」的标记 |
| 分离式近摄镜(split diopter) | 割裂张力/两焦点并置对峙 | 近远景同时清晰、中间虚化，把两平面强塞入同画对峙 |

### 景别

| 要素 | 情绪/功能 | 一句话机制 |
|---|---|---|
| 大远景(EWS) | 渺小/孤独/宿命/敬畏；交代地理时空(建立) | 人被压缩到近乎不可见，读出个体在世界前的无力 |
| 远景(LS) | 交代人物与环境关系/事件全貌；客观旁观 | 人与空间同框、信息以「场」为单位，情绪卷入度低 |
| 全景(FS) | 完整肢体动作/姿态/造型；登场亮相 | 完整身体入框、肢体连续不被裁切，强调「做了什么」 |
| 中景(MS) | 中性/日常/对话叙事主力(万能景别) | 同容手势与面部、接近社交距离，中立自然 |
| 牛仔/美式镜头 | 蓄势/对峙/随时拔枪；英雄气场 | 下切到大腿枪套高度，让「手—枪」关系可见 |
| 中近景(MCU) | 访谈感/可信/亲切而不越界 | 面部为主、肩胸稳定，进入个人社交距离，情绪读取增强 |
| 近景(CS) | 亲密/专注/情绪升温 | 环境基本排除、锁定面部，从旁观切换共情 |
| 特写(CU) | 强烈情绪/心理揭示/亲密或压迫 | 面部占满、微表情放大，强制进入主观情绪无法回避 |
| 大特写(ECU) | 极端张力/悬疑/恋物凝视/心理临界 | 视野压到单一细节(眼/手/物)，生理性紧迫不安 |

### 构图与空间

| 要素 | 情绪/功能 | 一句话机制 |
|---|---|---|
| 对称/单点透视对称 | 秩序/控制/庄严仪式；过度则诡异不安 | 完美平衡触发掌控读取，但自然罕见绝对对称、过度即生不安 |
| 三分法 | 自然平衡/舒适/动态稳定 | 焦点落三分交点符合人眼扫描，平衡又不呆板 |
| 中心构图 | 强制聚焦/对峙/孤立/稳定或压迫 | 主体钉中心剥夺视觉出口，迫直视生对峙或被困 |
| 大量负空间 | 孤独/渺小/疏离/存在主义空虚 | 大片空白压低主体占比，放大人相对空间的无力 |
| 引导线(灭点/道路/铁轨) | 牵引视线/纵深/宿命不可逆/期待 | 线条把视线强制导向灭点，制造「被引向某处」的必然 |
| 框架式框景(门/窗) | 窥视/被困/幽闭/隔离 | 画内再框一层把主体关进框里，暗示困境或偷窥 |
| 前景遮挡 | 窥视/隐秘/被监视/纵深共谋 | 前景物半挡镜头，像藏在物体后偷看 |
| 低角度仰拍 | 权力/支配/英雄/威胁/崇高 | 由下往上使主体高大压过视线，等同仰视强者 |
| 高角度俯拍 | 脆弱/渺小/无力/被审视 | 由上往下压低主体显弱小，观众俯视弱者 |
| 顶视/上帝视角 | 宿命/抽离/图案化冷漠/全知审判 | 垂直俯瞰把人变棋子图案，剥离主观代入 |
| 垂直支配(强垂直线) | 权力等级/压迫/囚禁/向上崇高 | 强垂直线分割画面制造高低等级或牢笼意象 |
| 破碎倾斜/荷兰角 | 不安/失衡/迷乱/疯狂 | 地平线倾斜破坏内耳平衡预期，生理性紧张 |
| 过多头顶空间 | 渺小/被压/脆弱/被上方力量凌驾 | 头顶大片空白把主体压向画面下方 |
| 头顶空间过少/切顶 | 紧迫/幽闭/压抑/躁动 | 顶边紧贴或切头顶挤压，像被天花板压住 |
| 满构图/密集拥挤 | 幽闭/窒息/混乱/信息过载/焦虑 | 画面塞满不留喘息，视觉负荷转心理压迫 |
| 极简/空旷构图 | 平静/孤独/冥想/存在主义空茫 | 极少元素大量留白，情绪转向沉思或空落 |
| 对角线构图 | 动感/张力/不稳定/能量 | 对角线打破水平垂直静止，制造运动矢量 |
| 三角/金字塔构图 | 稳定/平衡/和谐/层级清晰 | 底宽顶尖天然稳定结构，自动排出主次 |
| 水平线主导 | 平静/安宁/稳定/停滞 | 水平线呼应地平线与躺卧姿态，关联休息静止 |
| 前中后景层次/深空间 | 沉浸/世界真实厚度/纵深张力 | 前中后景同时清晰或分明，制造可走进去的三维 |
