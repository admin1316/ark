# 模块: empty-shot（professional-cinematic-image 子模块，按需加载）

### 空镜提示词（场景镜头/纯场景的生图规范——该场景时场景，空镜不是废图）

- **空镜类型**：纯环境（地理/时代/氛围建立——新场景第一张必用）· 情绪空镜（自然呼应人物内心：暴雨/废墟/天晴——环境=情绪外化）· 道具特写空镜（墙上照片/桌上信/远景人影——伏笔埋设）· 时间空镜（钟表/季节/光影位移）
- **空镜必须有'叙事锚点'**：画面里一个可被记住的元素（唯一亮部/异样物件/移动痕迹/远处的灯）——空镜无锚点=纯壁纸；叙事锚点写具体（'云海深处一座殿宇亮起暖金灯火'而非'氛围感'）
- **空镜必须有动态元素（静止中的动）**：至少一个动态——云海流动/水珠滑落/光柱移动/尘埃漂浮/窗帘微动；'悬而未落'比'正在落'更有张力（露珠悬停/雨滴半空/雪片将触地）
- **空镜构图即情绪**：对称仪式感（威严/神圣）· 大留白（孤独/空旷）· 低机位压迫（敬畏/渺小）· 前景框景（窥视/纵深）；空镜允许非常规构图
- **空镜与人物图的衔接**：空镜的叙事锚点要与人物图呼应（空镜里亮灯的窗→人物图里窗前的人）；空镜先出图建立世界，人物图再进入——两张图可成组使用
- **空镜适用全部纪律**：亮度锚定（主体=锚点物，中间调清晰）· 实拍质感（胶片/镜头/光学缺陷）· 场景美术四要素（时代/阶级/情绪/叙事）· 调色方案（四型+唯一暖色逻辑）——空镜不是'随便拍个景'，是叙事的一部分
