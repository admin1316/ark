# 模块: expression-scene（professional-cinematic-image 子模块，按需加载）

### 表情细节与场景动态提示词（写实面部特写 / 群像 / 环境叙事，关键帧与海报用）

- **写实面部特写（人物关键帧/海报，按部件写进提示词）**：眼（泛红血丝/红肿发胀/悬泪晃动/视线方向）、眉（眉心收紧/川字纹）、额（深浅横纹）、唇（颤动/下唇被气流翻卷/嘴角水丝）、鼻（鼻翼翕动/鼻头泛红/清涕）、面部肌肉（牵动/下颌抽搐）、生理（泪落路径/呼吸引起的肩颈起伏/水光）；提示词选 4-6 个部件写实即可，全部件堆砌会触发 AI 恐怖谷；**矛盾微表情**必须写（'嘴角释然浅笑同时眼中蓄泪'）——复合情绪是人脸生成避免僵化的关键
- **群像（多人关键帧/海报）**：主角色给完整面部细节；次角色给 2-3 个可辨细节（捂嘴的手/按桌角的指节/别过脸）；背景角色给姿态+1 细节（筷子停住/伞僵半空）；写'谁先谁后'的反应层次（焦点先动/次焦点延迟/背景最后），禁止'所有人都震惊'式同步
- **群像防克隆纪律（AI 群像最大通病：千人一面/克隆阵列——必须显式破掉）**：① **面孔差异**——写'每个人面孔各不相同（年龄/性别/脸型/五官各异）'，近景 3-5 人逐人给一个面部特征（老者白须/少年剑眉/女子凤眼）；② **动作差异**——每人一个微动作（捻须/闭目/持盏/抚琴/目视前方/低首），禁止'所有人端正坐姿'式复制；③ **服饰差异**——主色调统一但细节各异（纹样/发冠/配饰/衣料质地），禁止'一模一样的袍子'；④ **密度分级**——近景具体刻画（3-5 人有名有姓的特征）→ 中景群体轮廓差异 → 远景阵列缩小到轮廓/剪影层次（远景看不清脸，AI 反而堆复制——远景写'远景人物缩小为轮廓层次，不刻画面孔'）；⑤ **负面词必加**——'无重复面孔/无克隆人/无相同人物复制/无千人一面/无相同姿态重复/无相同服饰重复'；'整齐'是姿态的整齐（如'坐姿端正如棋'），不是长相和服装的整齐——文学修辞（'像摆好的棋'）翻译时只保留姿态感，五官服饰必须各异
- **场景动态（环境叙事提示词）**：动态环境元素写四要素——初始状态（雨丝密度/灯光亮度/蒸汽方向）→ 触发（事件）→ 变化（水珠滑落路径/灯光呼吸/雨点节奏）→ 与人物情绪关系（呼应或反衬：'雨声骤大呼应崩溃，灯光恒定反衬'）；静态图用'瞬间冻结'法：选动态链中信息量最大的一帧（泪悬不落/雨点停在半空/蒸汽凝住）——'悬而未落'比'正在落'更有张力
- **景别密度（提示词同样适用）**：特写=部件细节；中景=关键 3-5 项；全景=1-2 项+姿态；群像全景=焦点 2 项+背景姿态；负面约束里加'无表情僵硬/无恐怖谷/无塑料皮肤'
- **与角色资产衔接（关键帧/海报必带锚点）**：人物关键帧必须携带 novel-characters 交付的锚点（CH 编码特征：红绳/伤疤/发型/标志物）与材质参数（皮肤 SSS/布料粗糙度/金属 IOR）与表演七段链段位（蓄力/引爆/余波——画哪段写哪段，不混段）；面部细节与群像分配引用其群像定位（焦点型/次焦点型/背景型）；关键帧是角色资产的下游消费者，锚点缺失 = 该图返工

- **特写的电影语言**：特写给手/细节比给脸更有力量（指节发白/揪裙缝/水珠滑落）；特写必须携带可见细节，不拍空情绪
- **透视的运用**：仰视=崇高/压迫（拍巨物从头顶压过来），俯视=渺小/掌控（拍人物被环境吞没）；广角靠近主体强化透视张力
- **机位的叙事**：低机位贴地拍积水反光=暗示地面是路径；主体偏离中心+负空间=孤独/等待；前景遮挡=窥视感
- **光色的纪律**：全片冷调时唯一暖色=危险信号；用'光的意外'（唯一光源却带来压制）制造不安
