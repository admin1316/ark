# 模块: spectacle-card（professional-cinematic-image 子模块，按需加载）

### 奇观记忆点速查卡（让画面令人难忘，至少一个）

- **光的意外**：一个不合常理却成立的光源（生物自体内发光/云层裂开一线天光/城市灯光只为它点亮）
- **尺度的背叛**：用一个日常小物对比巨大存在（鸟/路灯/晾衣绳上的衬衫在生物脚下显得极小）
- **静止中的动**：宏大存在保持静止，但一个细节在动（它的衣摆/周围的尘/云的流动）
- **倒影/反射**：生物倒映在玻璃幕墙/水洼里，画面双重视觉
- **方向的对峙**：主体不看向观众/城市，看向一个不可见的方向——把悬念留给画外
- **温度的冲突**：在冷调环境里给主体一个唯一暖色（或反之）
