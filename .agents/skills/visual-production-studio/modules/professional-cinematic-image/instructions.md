# 专业电影感生图提示词

主文件保留核心工作流与全局纪律；具体技法按任务读取对应模块（每个 ≤80 行，一次只读 1-2 个）。

## 核心

把**情绪意图翻译成电影视觉决策**来写生图提示词，同时**克制、去 AI 感**。每个镜头、焦段、构图、景深、光、色、质感的选择都必须服务想要的情绪——绝不把术语当通用提质词堆砌，绝不写空洞的"电影感/史诗/8K/大片质感"。

默认**只写和优化提示词、不出图**（用户明确要求生成时才出）。输出语言跟随用户。默认面向 **GPT Image 2**，同样适用 **Nano Banana**。

用户要求细致表情、哭戏或情绪递进时，必须先完整读取 [真人微表情与连续表演合同](../_shared/micro-expression-performance-contract.md)。每一个人物关键帧都必须由其所在镜头的 `performance_state_id` 推导，不能重复粘贴通用悲伤/喜悦模板。单张电影关键帧只能冻结其中一个阶段：按景别写眼、眉、嘴、呼吸、视线、手势和泪水在**当前瞬间**的状态；删掉"缓慢、逐渐、随后、最后、反复"等时间推进词。完整递进必须先拆成多张关键帧，不能让一张静帧同时承担整段表演。

> **深档索引**：技能内 >80 行的深档（方法论/风格库/流程文档）不默认加载；需要时先查 `knowledge/index.md` 的用途→章节→只读对应小节，并按文件头 metadata（loading: on-demand）判断。
> **震惊工程**：产出必须过震惊点检查——画面/章节/方案里至少一个观众预期之外的元素（反常元素/情绪炸弹/隐喻层/唯一性指纹），标准见 `../_shared/shock-engineering.md`。先专业后震惊，顺序不能反。
> **画幅适配**：横屏/竖屏/宽银幕按目标画幅出——横竖是两套构图语言（竖=纵向构图+拇指区，横=横向引导线+地平线），支持安全区一版双出；标准见 `../_shared/aspect-ratio-adaptation.md`。

## 全局纪律（不读模块也必须遵守）

- **亮度锚定**（最高优先级）：暗环境+亮主体——先写主体亮度（面部中间调清晰）再写环境（深灰层次）；死黑 ≤10% 只在角落；暗词 ≤3；负面含"无整体过暗/无死黑一片/无主体淹没在阴影中"
- **主光保底**：人脸永远侧顶 45° 主光（五官可辨）+ 发丝金边轮廓光；禁止强逆光人脸
- **单主体单焦点**：一张图只讲一件事，只有一个视觉焦点；信息超焦点=拆图
- **确定性**：不留未决选项（不写 or/或/斜杠选项），每个变量只选一个
- **坐标钉死（空间构图必写）**：每个关键元素给归一化坐标（画面左=0 右=1 上=0 下=1）——主主体写精确交点（"人 x=0.30、y=0.65，头 y=0.62"），船/门/光柱等大元素写范围（"船 x=0.15-0.55、y=0.55-0.90"），群像写区域（"仙群 x=0.86-0.96、y=0.30-0.50 水平横带"）；留出明确的中间空域作视线通道；禁止"船挤窄条/人船分离/群像挤成竖线"（实测高频失败）；出图后按坐标 ±10% 验收
- **物理连接（画面元素不许悬浮）**：每个元素回答"从哪来/落在哪/和谁连接"——光柱必须落点（水面光斑承接）、人物必须有来处（来路/痕迹/方向线索）、光源必须有动机（可见的发光体）；禁止"光柱悬空贴图/人物凭空出现/光源无来源"；实测这是"AI 拼贴感"的根源
- **Anti-Slop 词纪律（开头的价值）**：提示词开头第一句给主体+动作（最值钱的注意力位置），不给 cinematic/epic/8K/masterpiece 等空词；质量词全部换成可执行细节（"weave visible"而非"detailed"）；负面不堆叠（负面召唤原理：写"画面里有什么"而非"没有什么"），只留平台约束位（no text/no watermark）

## 写作流程

1. **抽场景**：主体、动作、环境、时间、情绪温度、故事潜台词、必须保留的细节。若主体是人物特写，锁定当前表演阶段/刺激来源/视线目标/呼吸状态/泪痕连续性，只冻结一个瞬间。
2. **先定电影策略再写字**（不许先写字再补形容词）：四轴各选一个——光（实用光源/窗光/门缝光/单光源低调等）、构图（偏心/负空间/前景分层/框景/反射等）、色（冷暖互补/烟草琥珀阴影/褪色泥土调等）、质感（35mm 颗粒/halation/柔高光/抬黑位等）。拿不准查 [references/emotion-visual-table.md](references/emotion-visual-table.md)。
3. **写一条强正向提示词**：把具体视觉选择写进提示词，不写 "make it cinematic" 空指令。
4. **加一行简短 avoid**（仅在有用时）。
5. 用户给了提示词就**保留其意图并改写**，不要把主体替换成通用电影场景。

先想：观众位置/权力关系/空间心理/叙事焦点/视觉温度/真实程度——依次推断再写。

## 出图前检查（七项全过才交付）

1. **开头**：第一句是主体+动作？（不是 cinematic/epic 空词）
2. **坐标**：关键元素都有归一化坐标？有中间空域视线通道？人船不分离？
3. **物理连接**：光有落点？人物有来处？元素之间不悬浮？
4. **亮度**：主体中间调清晰？死黑 ≤10% 只在角落？
5. **材质**：每个关键道具都有具体材质词（织纹/木纹/水珠）？
6. **禁入/必须**：本帧禁入清单与必须清单写了吗？
7. **负面**：只留平台约束位（no text/no watermark），无堆叠？
