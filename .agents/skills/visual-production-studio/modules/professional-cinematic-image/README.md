## 这是什么？（用一句话说明白）

平时你让 AI 画图，随手写「电影感、大片、8K、高清」，出来的图往往一眼假、很「AI」。

这个技能换了个思路：**先想清楚你要什么"感觉"（害怕？温暖？孤独？高级？），再倒推出该用什么镜头、光线、构图、颜色**，最后给你一段**照着抄就能用**的提示词。出来的图更像电影里的一帧，而不是廉价广告图。

它**只写提示词、不直接出图**——你把提示词拿去 GPT Image 2、Nano Banana、即梦等任何生图工具里用。

## 🧓 怎么安装？（三步，照着做就行）

> 前提：你电脑上装了会用 Skill 的 AI 助手（比如 Claude Code、Codex）。

**第 1 步**：把这个仓库下载到电脑。
点这个页面右上角绿色的 **`Code`** 按钮 → **`Download ZIP`**，下载后解压。

**第 2 步**：找到电脑里放技能的文件夹。
- Windows：打开「文件资源管理器」，在最上面地址栏输入下面这行，回车：
  ```
  %USERPROFILE%\.claude\skills
  ```
- 苹果 Mac：打开「访达」，按 `Shift+Command+G`，输入下面这行，回车：
  ```
  ~/.claude/skills
  ```
（要是没有 `skills` 这个文件夹，就自己新建一个，名字就叫 `skills`）

**第 3 步**：把第 1 步解压出来的整个文件夹，复制粘贴进去。
装完，把 AI 助手关掉再打开一次。**完成！**

## 怎么用？（说人话的例子）

打开你的 AI 助手，直接用中文说你想要什么，比如：

> 「帮我写一条**电影感**提示词：**下雨的旧城街头，一个人很孤独**」
>
> 「把这句话写成电影截图质感的提示词：**五个战士面对沙暴里的巨兽，很压迫**」
>
> 「帮我写一张**温暖治愈**的咖啡馆图片提示词」

它会先分析你要的情绪，再给你一段可直接复制的提示词，还会附上「避免」清单帮你去掉 AI 味。
