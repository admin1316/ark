# 可视化分镜质检

## 叙事可读性

- 连续看三格，能否说出“谁做了什么、为什么重要、结果怎样”？
- 反应镜头是否放在观众需要确认情绪或信息的位置？
- 装饰性画格是否挤占了转折、动作接触或结果画格？

## 轴线与屏幕方向

- 同一主轴上的摄影机是否保持在同一侧？
- 人物 A 看向画右时，反打中的人物 B 是否看向画左？
- 人物或车辆的运动方向是否跨镜头保持？
- 若方向改变，画面中是否出现转身、绕行、中性镜头或新轴建立证据？

## 空间与透视

- 地平线是否对应镜头高度？
- 平行边是否归向一致的消失点？
- 圆、轮子、拱门和圆柱的椭圆轴是否正确？
- 人脚、家具、建筑是否落在同一地面系统，没有悬浮和无意穿插？
- 焦段与机位距离是否共同产生所描述的压缩或夸张，而非只写一个毫米数？

## 构图与画幅

- 缩略图大小下是否仍有唯一视觉重点？
- 画格留白是在表达压迫、孤独、期待或方向，而不是空洞？
- 群戏是否通过阵营、轮廓、明暗和流线指向主动作？
- 横竖改版是否重新构图，而非平均裁切？

## 角色与状态

- 身份、年龄、脸型、发型、服装层级和身高关系是否一致？
- 道具在哪只手、朝向何处、是否打开或破损？
- 污渍、伤口、雨水、发丝、衣物破损是否只增不减，除非剧情处理？
- 主光方向、时间和天气是否在同场稳定？

## AI 生成专项

- 发现换脸：加强身份参考，减少无关参考图，只重做该格。
- 发现空间漂移：先修场景母版和站位描述，再重做覆盖镜头。
- 发现姿势僵硬：改写为目标驱动的关键姿势，明确重心、接触和反馈。
- 发现画面过度精美但信息不清：降级为灰阶块面，删材质词，恢复轮廓与关系。
- 发现文字乱码：删除图内文字，在 HTML 排版层标注。

## 结论等级

- `PASS`：可以进入动态预演或视频执行。
- `REDO`：镜头意图正确，但画格层失败；只重画该格。
- `RETURN`：上游镜头设计、场景地理或连续性定义冲突，需要退回修正。
