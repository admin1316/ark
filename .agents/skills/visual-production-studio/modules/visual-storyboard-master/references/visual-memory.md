# 模块: visual-memory（visual-storyboard-master 子模块，按需加载）

### 画格惊艳速查卡（每场至少一个画格有记忆点）

- **姿态的张力**：一个不完全稳定的姿势（重心将移未移/手悬半空/身体前倾将倒）
- **光的引导**：画格内唯一亮部指向戏核（脸/手/关键道具），其余沉入暗部
- **前景的利用**：透过前景物体拍主体（门缝/栏杆/树叶），制造窥视感
- **关系的构图**：用距离/高度/朝向表达权力（高大者低头/两人之间留出的空隙）
- **细节的锚点**：每个角色一个可辨识的小特征（旧伤/戒指/袖口磨损），跨画格稳定出现
- **透视的纪律**：先定消失点与地平线再画主体；仰视=崇高/压迫，俯视=渺小/掌控；平行线必须汇聚正确（广角更明显），错误透视是最显眼的业余信号
- **机位的选择逻辑**：事件开始用极端角度切换标记；对峙用平视中近景（不偏袒）；压迫用低机位仰拍；权力关系用高度差（强者高位，弱者低位）
- **特写的位置**：特写给手/细节比给脸更有力量；特写必须携带可见细节（指节发白/揪裙缝）；从特写摇出到环境=从内心到世界
- **画格的构图冲击**：非常规角度（贴地/缝隙/透过前景）· 主体偏离中心 + 负空间 · 斜线构图制造不稳定感
### 画格表情与场景细节刻画（特写格的面部部件清单 + 场景动态元素，画格描述必含）

- **面部部件清单（特写格按此选件，每部件一个可验证细节）**：眼（泛红血丝/睁大/红肿/视线方向与躲闪/悬泪晃动）、眉（眉心收紧/双眉下压/川字纹）、额（动态深浅横纹）、唇（收紧/颤动/下唇被气流翻卷/嘴角水丝）、鼻（鼻翼翕动/鼻头泛红/清涕）、面部肌肉（牵动/反复松紧/下颌抽搐）、生理（泪落路径/呼吸加重/水光）；画格描述中特写格至少 4 个部件，中景格 2-3 个，全景格 1 个姿态细节
- **矛盾微表情（画格的记忆点来源）**：至少一处复合情绪——嘴角释然浅笑+眼中蓄泪/手在擦泪肩在抖/笑着说'没事'但指节发白；画格描述写明'笑的轮廓与哭的预兆叠在同一张脸上'
- **场景动态元素（把环境画成'会表演的角色'）**：动态环境（雨/灯/蒸汽/钟/风/水珠）在画格描述中给四要素——初始状态（雨丝密度/灯光亮度/蒸汽方向）、触发（什么事件让它变化）、变化过程（水珠沿玻璃滑落的路径/灯光呼吸频率/雨点节奏）、与角色的关系（呼应或反衬：'雨声骤大呼应崩溃，灯光恒定反衬——它不知道有人要死了'）；每格至少 1 个动态环境元素参与叙事
- **群像画格（三级+时间差落位）**：焦点角色占构图主体（完整情绪链关键帧）；次焦点给可辨 2-3 细节（捂嘴的手/按桌角的指节）；背景给姿态+1 细节（筷子停住/伞僵半空）；画格内标注'谁先谁后'的反应顺序（焦点→次焦点→背景）——群像格用连续 2 格拆分反应链（第一格焦点破防+次焦点转头，第二格背景全体反应）
- **与上游衔接**：面部部件与群像分配引用 novel-characters 表演七段链/群像定位；特写格的表情状态必须与 director-master 分镜表'画面内容'列的表演链段位一致（蓄力格画蓄力、引爆格画引爆，不混段）
