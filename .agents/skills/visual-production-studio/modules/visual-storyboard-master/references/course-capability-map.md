# 分镜能力地图

本地图将用户提供的本地学习材料转化为通用分镜能力。技能不保存课程原图，不复刻大段原文，只保留可执行的方法、调用条件与检查规则。

## 一、分镜头脚本设计

| 章节 | 转化后的技能能力 | 何时调用 | 检查重点 |
|---|---|---|---|
| 第一章 叙事艺术概论 | 从故事目标、场景目标和观众情绪反推画面；建立首镜基调与视觉一致性；用暗示和留白调动观众 | 开始整场分镜、首场/首镜设计、风格漂移诊断 | 画面是否服务叙事；删掉后不影响叙事的元素是否仍被滥留 |
| 第二章 静帧的绘制与构图 | 提炼对象“精气神”而非机械复制；使用视点、布光、明暗和轮廓改变观众感知 | 单格不够有力、角色表情不准、同一场景需不同情绪版本 | 第一读数、明暗大形、视觉中心、环境是否传递情绪 |
| 第三章 构图原则 | 用简化图形、张力线、引导线、面积对比和低/高视点组织注意力 | 画面杂乱、重点不清、压迫或释放感不足 | 3 秒缩略图是否读懂；线条是否把眼睛引向戏核 |
| 第四章 动态分镜 | 连锁反应、对比、高潮递进、动作—反应关系、180 度轴线与新轴转换 | 追逐、动作、空间转换、高潮镜头组、越轴风险 | 感知—准备—接触—结果顺序；轴线是否被建立和转换 |
| 第五章 图像小说 | 角色形状语言、连续画格、页面节奏、拟声词和对话框作为视觉元素 | 漫剧、漫画、图像小说、竖屏连续画格 | 角色可辨识性；画格组合是否形成阅读路径与节奏 |

## 二、画幅与分镜

| 章节 | 转化后的技能能力 | 何时调用 | 检查重点 |
|---|---|---|---|
| 第一章 画格内部空间 | 把画格视为力场；利用平衡/失衡、压缩/释放、主体位置和负空间制造张力 | 主体位置选择、压迫/孤独/安全感表达 | 主体与边缘距离是否产生所需心理；负空间是否有叙事作用 |
| 第二章 构图流动基础 | 用弧线、三角、之字、垂线等组织多人和环境；保留缩略图的新鲜度 | 2–5 人构图、角色层级、构图僵硬 | 形状关系是否明确；精修是否损失原始动势 |
| 第三章 构图流动练习 | 为动作赋予目的，用作用力、反作用力和拐点设计视觉流向 | 动作姿势机械、画面缺乏动势 | 动作是否有目标；流线是否存在可读的转折点 |
| 第四章 群戏篇 | 用服装、头部、肢体、武器和环境线条把群体动作汇聚到叙事中心 | 战斗、人群、仪式、体育、神庭群像 | 阵营是否瞬间可辨；群众细节是否淹没主动作 |
| 第五章 1.85:1 与 2.35:1 | 画幅转换时保留最有价值的信息和动势发散点，按叙事选择裁切或扩展 | 横竖改版、宽银幕到平台画幅、重构图 | 不能平均裁切；关键方向、目标物和压力关系必须保留 |
| 第六章 非常规构图 | 在水平画幅表现垂直主题，或反向处理；用极端俯仰、影子和尺度替代直接展示 | 巨物、高塔、深渊、垂直竖屏、异常空间 | 非常规选择是否帮助主题，而非只求奇怪 |
| 第七章 分屏与分区构图 | 三分、二分、四分和区域交叉点组织叙事点与节奏 | 对话、双人对峙、分屏、多叙事点 | 分区是否服务关系；避免机械把主体放三分点 |
| 第八章 关键画面研发 | 从戏核、物理元素、形状语言、视觉权力和镜头组关系研发关键帧 | 场次第一次视觉开发、关键帧和场景母版 | 先明确戏核；关键画面是否能代表整组镜头 |
| 第九章 图像小说中的画格 | 用画格尺寸、形状、跨格和双页关系构建页面级语言 | 漫画页、长图、竖屏条漫、分镜板节奏 | 单格与整页是否同时成立；阅读顺序是否无歧义 |
| 第十章 变化过程与图例分析 | 从草图迭代到定稿；同剧情重构为不同画幅；逐格诱导观众获取信息 | 方案比较、版本迭代、横竖双版本 | 每次变化解决了什么；是否保留历史版本与决策依据 |

## 三、场景透视

| 章节 | 转化后的技能能力 | 何时调用 | 检查重点 |
|---|---|---|---|
| 第一章 基础知识 | 视高、视线、视觉中心、视锥、画面平面和观者 POV | 所有新场景的空间建立 | 谁在看、眼睛多高、镜头指向何处必须明确 |
| 第二章 平坦正方形表面 | 单点透视、平行线汇聚与二维平面在空间中的变化 | 正视走廊、门窗、道路、平直空间 | 平行线是否汇聚到正确消失点 |
| 第三章 立方体与单点透视 | 用基本体积搭建场景；从艺术草图反推透视支撑 | 室内、街道、箱体建筑、道具尺度 | 先有构图意图，再用透视校正；不能让网格反客为主 |
| 第四章 两点透视 | 旋转物体与机位、双面可见、倾斜地平线和建筑结构 | 斜看建筑、转角、城市、动态机位 | 两组平行线各自归点；倾斜地平线时垂线关系一致 |
| 第五章 多重消失点 | 同场多个旋转物体、不同方向物体群、尺度迁移和接触关系 | 杂乱道具、车辆、人群与复杂街景 | 每组方向各有透视系统；物体不能无意重叠或漂浮 |
| 第六章 三点透视 | 课程目录存在但当前素材为空；保留为待补模块，不虚构课程内容 | 极端仰拍、俯拍、高塔、坠落 | 需用通用三点透视规则并明确非课程提取 |
| 第七章 倾斜面 | 斜坡、楼梯、坡道和多段地形的独立消失点与高度传递 | 山路、屋顶、阶梯、起伏地形 | 平坡转换是否清楚；建筑与坡面是否处于同一空间系统 |
| 第八章 弯曲的线 | 透视中的圆、椭圆、圆柱、车轮、拱门和不规则曲线 | 轮子、穹顶、柱体、管道、弧形建筑 | 长短轴、接触点和椭圆开合是否服从视角 |
| 第九章 立面/平面/剖面 | 从平面图、立面图、剖面图和观察站点构建镜头空间 | 复杂场景母版、重复机位、跨镜头一致性 | 镜头能否回到同一平面图；尺度与站点是否可复现 |
| 第十章 镜头 | 广角、标准、长焦对空间深度、压缩、畸变和取景范围的影响 | 焦段选择、人物与背景关系、镜头匹配 | 焦段不是景别同义词；机位距离与透视效果必须一致 |
| 第十一章 徒手绘制与草图 | 观察—找关键点—连接体积；用网格、角度、比例和负空间快速校正 | 缩略图、现场草图、生成图错误复盘 | 线条是否描述体积；局部漂亮不能牺牲整体比例 |
| 第十二章 构成笔记 | 把透视、明暗、线条、形状和角色关系综合为构图诊断 | 最终分镜 QC、复杂画面复核 | 技术规则最终是否回到叙事重点和空间可读性 |

## 路由原则

- 叙事不清：先读“分镜头脚本设计”。
- 单格无力或画幅不合：读“画幅与分镜”。
- 空间漂移、人物悬浮、建筑变形：读“场景透视”。
- 同时出错时按“叙事 → 空间 → 构图 → 细节”修复，不能用精修掩盖上游错误。
