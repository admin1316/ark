# 模块: manga-style（visual-storyboard-master 子模块，按需加载）

### 漫剧画格风格化技法（漫剧/动态漫画专用，与电影分镜不同）

- **风格锁定**：每部漫剧先定'画风卡'——线稿粗细（细线=精致/粗线=热血）、上色法（平涂/厚涂/赛璐璐）、网点密度、人物比例（写实/Q版/2.5头身）
- **漫剧竖屏构图**：9:16 画幅；重要信息放中上 1/3（拇指区=安全区）；对话框贴边不遮挡主体脸；竖屏的纵向构图优先（人物立幅/视线上下）
- **特效字**：爆点用冲击字（描边/变形/放大）；情绪用飘字/气泡；音效拟声字（砰/咔/嘶）入画但 ≤ 画面 15%
- **网点与纹理**：情绪压抑=暗网渐变；回忆/梦境=噪点/柔边；危险=斜纹/裂纹网点；网点跟随光源方向
- **色彩体系**：每集一个主色情绪（蓝=压抑/红=冲突/黄=回忆暖）；全剧保持统一肤色/环境色；爆发点用补色对撞（青vs橙）
- **动态漫画动效**：漫剧画格=静态底+局部动效（发丝飘/雨下落/眼神闪烁/对话框弹出）；动效点选'信息焦点'而非全格乱动；每格动效 ≤ 2 处
