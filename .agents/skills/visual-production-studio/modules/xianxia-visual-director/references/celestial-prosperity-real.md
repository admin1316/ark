# 模块: celestial-prosperity-real（xianxia-visual-director 子模块——天庭"繁华且高级"实拍法，联网研究沉淀）

> 来源：8 组联网检索（86版西游/妖猫传/封神/三生长月与凤行质感争议/飞升威亚/聊斋志怪美学/山水画留白）+ xianxia-visual-director 互证。直接指导《人间香火录》天庭生图。

## 一、金碧辉煌 vs 塑料感的分界线（核心）
- **高级**：真材料（木的厚/漆的润/金属的氧化）+ 动机光源（烛火是唯一光源，光打在真材料上）+ 局部装饰（繁缛只集中柱础门楣）+ 暗部带冷色
- **廉价（AI 默认）**：自发光 + 无材质逻辑 + 满屏高饱和 + 全局橙色暖光溢出——金变成"发光贴图"而非"材料"
- 86版《西游记》天庭高级的原因：棚内实木搭景+红金彩绘+真烛光，云海用干冰/烟分层——真实物料的物理重量
- 《妖猫传》极乐之宴：光源写实（烛火灯笼）+ 密度分层（舞者→楼阁→万点灯火）——华丽来自"重复的灯"而非"满屏的金"
- 《封神》昆仑：玉石白+极简留白，繁缛装饰只集中一两处
- 《长月烬明》等被批廉价：背景过度虚化、云海纯CG贴图、全画面橙色光溢出

## 二、三层结构（大场面的纵深制造）
远景天际线（云海/天光/远宫剪影）→ 中景建筑群（重复斗拱楼阁沿透视线收敛成韵律）→ 近景人物
- 人眼靠"已知物"反推尺度；三层递进才有纵深；一格里堆满元素=无主次无深度
- 生图执行：人物占画面 1-3%；中景建筑沿透视线重复收敛；远景大气透视变淡；层间用云隙/空气隔开（空气占 40-60%）

## 三、留白哲学（"计白当黑"）
- 云海=留白的功能化：有明度变化的空间信息（云的体积/边缘光/远处轮廓），不是空白也不是灰雾
- 玩具感=无体积无透视的纯白棉花云贴图
- 生图执行：云海压在主平台地平线之下，人物之上空气通透，薄雾只做层间纱，禁止全城罩灰

## 四、人物比例（敬畏感的来源）
- 剪影、极小人物（1-3%）、低机位仰视——观众用"人"当尺子量出环境之大
- 机位放人眼高度之下，"你仰视它"才有神性
- 生图执行：远景用 70-100mm 长焦压缩，近景用柱/檐/门做巨物前景框，人物背影居画面下 1/3

## 五、飞升镜头语言（实拍"飞"怎么拍）
威亚+鼓风机+慢镜头+逆光：真布料被风带出物理惯性，逆光勾轮廓（脸入暗、衣发光），升空后切远景、人物缩成一点穿云
- 布料的真实动态 CG 模拟不了；轮廓光让"发光"可信
- 生图执行：衣袂带风向与褶皱、人物边缘一条冷色轮廓光、脚下云海翻卷、有滞空感

## 六、中式怪谈：繁华天庭下的不祥感（《人间香火录》灵魂）
五手法（《聊斋》/《妖猫传》共用）：
1. **光不对**：暖烛变冷绿惨白
2. **色调突降**：高饱和骤转青灰
3. **静**：本应人声鼎沸却空无一人、无风无鸟
4. **空**：器物都在却无使用痕迹
5. **异常细节**：影子错位、多出一物、人脸模糊
恐怖来自"秩序被打破"——繁华人间的物理规则失效

## 七、实拍 vs CGI 分界（生图模拟"实拍优先"）
- 实拍管"接触物"：香炉/长案/灯笼/金器/长明灯/帷幔/真丝绸（近景器物）——人眼对近景材质最敏感
- CG 管"无限物"：云海体积/光效/粒子/远景建筑群——人眼对远景模糊最宽容
- 生图执行：近景道具带真实漫反射、投影与微磨损（蜡油/香灰/磕碰），远景靠大气透视淡出

## 八、生图执行口诀（对齐 xianxia 视觉总则）
五层空间（近巨框→承载台面→主殿→次级群→极远天光）· 40-60% 有内容空气 · 无栏杆 · 背影仙人 · 低机位仰视 · 近实远虚 · 禁全局橙色溢出 · 云海在脚下方 · 装饰只集中一两处 · 金=材料不是发光贴图
