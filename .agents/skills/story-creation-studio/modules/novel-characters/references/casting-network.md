# 模块: casting-network（novel-characters 子模块，按需加载）

### 选角参考与角色关系网（Step 5 后补出，选角表和关系网随角色资产交付）

- **选角参考（文字选角表，不依赖真人图）**：每主要角色给——气质关键词 2-3 个（'清冷疏离/骨相硬朗'而非'好看'）、参考类型（'往老牌青衣气质走'而非点名具体明星，避免肖像风险）、可辨识特征（眉骨/下颌/眼神/体态）、年龄区间与造型方向（发型/穿衣风格）；选角参考服务于三视图与关键帧的一致性，写'视觉提示词可直接引用'的表述
- **角色关系网（谁欠谁/谁怕谁/谁信谁，驱动群像戏与对白的底层结构）**：每对关系登记四要素——关系类型（血缘/爱恋/恩仇/利益/师生）、权力向（谁高谁低）、情感基线（信任/防备/愧疚/依赖）、未结清账（欠的/藏的秘密/未兑现的承诺）；关系网表随 cast.json 交付，分镜/群像设计时直接按'关系网'分配呼应/对比/对抗——群像戏中次焦点与焦点的默认关系（呼应者/对比者/旁观者）从这里取
- **关系网驱动规则**：任何两个角色同框时，默认从关系网取'情感基线+未结清账'作为潜台词来源（表面对话=关系网内容的遮掩）；冲突升级沿关系网的'未结清账'引爆（欠债的相遇=必然爆发）；关系网变更（和好/决裂/揭密）是重要剧情节点，变更后更新关系网表
