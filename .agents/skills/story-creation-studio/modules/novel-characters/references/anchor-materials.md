# 模块: anchor-materials（novel-characters 子模块，按需加载）

### 角色锚点编码与渲染材质参数（角色资产向下游传递的标准，Step 9 出卡时每角色必带）

- **角色锚点编码（衔接符号锁体系，编码 CH-XX 与小说/改编/分镜共用）**：每个角色登记不可漂移的锚点清单——外观锚点（脸型/发型/标志物/伤疤）、行为锚点（习惯动作/口头禅/步态）、随身锚点（饰品/武器/服装层级）；锚点描述用'可跨媒介验证'的语言（'右手腕红绳系蝴蝶结'而非'一条红绳'）；三视图/角色卡/视觉提示词必须包含全部锚点，禁止中途增删；图像提示词（含三视图/role prompt/turnaround）绝对禁止出现角色名、别名、作者名、作品名（图像模型对名字偏见极重，会画成它记忆里的角色）——描述这个人，不要叫他的名字；同样规定见 profile-pass.md 第 4 条
- **角色锚点 vs 表情库**：锚点是'无论什么情绪都在'的物理特征（红绳/伤疤/发型），表情库是'情绪驱动的瞬时状态'；出卡时分开交付——锚点进角色 JSON 固定字段，表情库进表演圣经，防止生成时把情绪状态误当锚点导致漂移
- **渲染材质物理参数（衔接电影级渲染规格书，供 Redshift/UE 等管线直用）**：每角色给四组材质参数——皮肤（SSS 半径 2-3cm/次表面 0.5-0.7/粗糙度 0.35/色温基底）、发丝（Hair Strand 物理解算/粗糙度 0.6-0.8/发色基底）、服装主料（布料微表面粗糙度：亚麻 0.8/丝绸 0.3/皮革 0.5/金属件 IOR 1.5）、特殊材质（眼镜/鳞片/纹身/伤疤等 IOR 与粗糙度）；三视图 prompt 与渲染规格书共用这套参数，保证角色资产从概念图到成片一致
- **主光适配备注（衔接主光保底纪律）**：每角色注明'最优主光方向与角度'（如侧顶 45° 暖金最佳，强逆光禁用）——分镜/关键帧阶段直接引用，避免下游把角色扔进逆光
