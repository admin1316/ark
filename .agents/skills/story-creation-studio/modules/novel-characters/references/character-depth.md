# 角色深度标准（行业顶级角色设计——皮克斯方法论 + 编剧行业规范）

> 来源：皮克斯编剧 Andrew Stanton（"所有好角色都有脊柱"）+ StudioBinder 角色设计分析 + 编剧行业通用规范。角色卡除了锚点/材质/音色，必须补"深度五件"——这是角色"有灵魂"与"纸片人"的分界线。

## 深度五件（出卡必带）

### 1. 角色脊柱（Spine）——内在马达

- 一句话说出潜意识驱动角色全程的目标（不一定是自觉的）：Marlin="防止伤害"、Wall-E="寻找美"、阿灯="被需要/不被抛弃"
- 脊柱不是"想复仇"这种表层动机——是**更深的存在性驱动**（安全/被爱/意义/自由）
- 落地：角色卡加"脊柱"一行，一句话（8-15 字）

### 2. 外部想要（Want）vs 内部需要（Need）——对立=戏剧引擎

- **外部想要**：角色自觉追求的东西（Woody=当 Andy 最爱的玩具；阿灯=救老周）
- **内部需要**：角色真正需要但自己不知道的（Marlin=学会信任放手；阿灯=承认自己救不了所有人，但仍选择去救）
- **黄金规则：want 与 need 必须对立或至少冲突**——Marlin 的外部想要（保护 Nemo）恰恰是伤害他的东西
- 冲突点 = 全剧戏剧引擎；角色成长 = need 战胜 want（或重新定义）
- 落地：角色卡加"Want / Need / 冲突点"三行

### 3. 灵魂创伤（驱动一切行为的伤口）

- 角色最深的伤口——塑造他的防御机制、恐惧、执念：林晚="曾写信求救却没人回应"→ 所以她做电台听陌生人说话
- 创伤不一定要写进正文——但角色卡必须有（行为逻辑的根）
- 落地：角色卡加"灵魂创伤"一段（2-3 句：发生了什么/他因此相信什么/他如何防御）

### 4. 压力揭示性格（角色的试金石）

- 角色在压力下如何行动 = 真实性格（平时都是表演）
- 设计两个压力测试：**小压力**（日常挫折→他的第一反应暴露习惯性防御）和**大压力**（生死抉择→他的选择暴露核心价值观）
- 落地：角色卡加"压力测试"两行（小压力反应/大压力抉择）

### 5. 脆弱点（皮克斯七原则：脆弱之处读懂角色）

- 角色最怕被看到的东西（羞耻/软弱/秘密）——观众爱角色的脆弱，不是强大
- 落地：角色卡加"脆弱点"一行（他死也不愿承认的事）

## 与现有卡字段的关系

| 字段 | 已有 | 本模块补 |
|------|------|---------|
| 锚点/材质 | ✅ 外观/行为/随身 + SSS/IOR | — |
| 表演七段链 | ✅ 情绪模板 | 深度驱动表演（创伤→防御→爆发方式） |
| 群像定位 | ✅ 焦点/次焦点/背景 | 关系网由 Want/Need 冲突驱动 |
| 弧光（novelist 侧） | ✅ 信念转变 | 弧光 = Need 战胜 Want 的过程 |

## 深度自检（出卡后逐项过）

1. 脊柱一句话能说出来？
2. Want 与 Need 对立/冲突？（不冲突=角色没戏）
3. 灵魂创伤能解释他 80% 的行为？
4. 压力测试：换一个角色套同样的压力，反应会不同？
5. 脆弱点会让人心疼还是无感？
