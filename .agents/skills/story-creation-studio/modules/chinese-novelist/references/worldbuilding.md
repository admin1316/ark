# 模块: worldbuilding（chinese-novelist 子模块，按需加载）

### 世界构建专家方法论（第一阶段 Q4-Q8 世界观环节的完整执行标准）

- **三层结构**：① 可见层（地理/建筑/服饰/饮食/技术/物价——读者眼见的）② 规则层（力量体系/社会制度/禁忌/代价——故事运行的）③ 隐喻层（世界观暗指的现实议题/主题——让故事有重量的）
- **规则三性**：一致性（已设规则不破例，破例=重大事件且要付出代价）· 可见性（规则通过情节展示而非旁白说明）· 代价性（能力/权力都有代价，无免费午餐）
- **设定冰山**：只露出 10% 设定，90% 藏在水下（通过对话/细节/行为暗示）；禁止设定倾倒（开局三页讲历史）
- **冲突土壤**：世界观的每个角落都要能长出冲突（资源稀缺/阶层对立/规则压迫/旧神与新政）；世界不是背景板而是发动机
- **反套路审查**：检查设定是否落俗（'天选之人''血统觉醒'类先例）；给经典设定加一个反转（力量来自诅咒/血统是骗局/预言是阴谋）
- **类型适配**：仙侠=修行体系+劫难代价；都市=组织暗网+资源争夺；悬疑=规则漏洞+信息差；每个设定都要服务类型情绪
