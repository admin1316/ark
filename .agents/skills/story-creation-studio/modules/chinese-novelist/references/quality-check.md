# 模块: quality-check（chinese-novelist 子模块，按需加载）

### 章节质量校验细则（重写前逐项检查，任一不过即重写）

- **钩子检查**：章末是否有钩子？钩子是否'改变读者对前文的解读'（强钩子）而非仅'有悬念'？
- **展示非讲述**：全文心理直述比例？'他意识到/她感到/内心'类表述是否已转成可见动作？
- **冲突密度**：本章至少一个冲突/转折；平淡章节（纯过渡）连续 ≤2 章
- **节奏**：快慢交替；无连续 3 段同速描写；高潮前有铺垫、后有余波
- **对话质量**：每场对话是否有'地位变化'或信息增量？纯闲聊段落删
- **感官密度**：每千字至少 3 处具体感官细节（视觉/听觉/触觉/嗅觉），拒绝'好看/很美'式空泛
- **人物声音**：每个角色说话方式是否可区分（无两人同声）？
- **连贯性**：时间/地点/道具/服装/伤损跨章一致；人物称谓一致（无突然改名）
- **字数**：目标字数 ±10%；过短=信息不足，过长=节奏拖沓（先压缩再补写）
