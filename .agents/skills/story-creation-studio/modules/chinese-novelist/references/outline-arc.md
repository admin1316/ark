# 模块: outline-arc（chinese-novelist 子模块，按需加载）

### 大纲节奏设计专家方法论（第二阶段规划：让 20 万字不垮的骨架）

- **三幕定位**（已有 plot-structures.md 的章节示例）：幕内再分'卷'，每卷 8-12 章、一个卷高潮；卷间留'呼吸章'（1-2 章低强度）
- **爽点分布律**：每 3-5 章一个小爽点（打脸/揭晓/获得），每卷一个大爽点（身份揭晓/实力跃升/关系确认）；高潮密度前 1/3 疏、后 2/3 密（网文留存律）
- **钩子链**：章章有钩子（章末钩子 → 下章开头回收）；卷末钩子升级为'翻卷钩'（改变读者对全书的解读）
- **多线并行**：主线 + 1-2 支线交错推进（支线每 3-4 章露一次面，不冷线）；支线最终汇入主线（支线不是废线）
- **伏笔管理**：伏笔台账（埋设章节/回收章节/类型：信息/物件/人物）；重要伏笔提前标记，防止烂尾；回收密度=埋设的 100%（能收全的才埋）
- **节奏曲线**：每卷张力曲线 = 升→停（假解决）→升→爆（卷高潮）→降（呼吸）；禁止直线上升（会麻木）也禁止均匀起伏（会平淡）
- **结尾工程**：大高潮前 3 章开始收线（每章收 1-2 条线）；结尾不新增新设定/新角色；终章必须回应开篇意象（闭环）

### 角色弧光设计专家方法论（人物从 A 到 B 的转变曲线，规划期就定）

- **弧光五问**：① 起点信念（他相信什么/害怕什么）② 终点信念（结局相信什么）③ 转折点（哪件事动摇信念）④ 代价（转变付出了什么——失去/背叛/牺牲）⑤ 残余（转变后仍保留的旧特质——人性不完美）
- **三种弧光**：成长弧（信念变强：懦弱→勇敢）、堕落弧（信念崩塌：正义→黑化）、发现弧（信念替换：复仇→放下）—— 每部作品主要角色至少一条
- **弧光与情节咬合**：每个卷高潮 = 弧光里程碑（卷一让他被迫直面恐惧/卷二让他第一次用新方式行动/卷三让他付出代价）；情节事件服务于弧光，不是弧光服务情节
- **反向角色**：主角的弧光需要'对照物'——一个做出相反选择的同类角色（他本可以成为的样子/他拒绝成为的样子）
- **缺陷即弧光起点**：人物缺陷 = 弧光要填补的洞（完美人物无弧光）；缺陷必须造成实际代价（吝啬者失去重要的人，才能开始改变）
- **弧光可逆检查**：结局的他看到开篇的自己会怎么评价？如果评价是'挺好的'，弧光太弱；如果'那个人是谁'，转变过大失真；要'我知道他为什么那样，但我不会回去了'
