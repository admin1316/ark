# 模块: guaitan-openings (chinese-novelist 子模块——顶级怪谈开篇拆解，联网研究沉淀)

> 来源：5 部经典开篇拆解（画皮/崂山道士/聂小倩/鬼吹灯/河神）+ 罗刹海市分析 + 中式vs日式恐怖对比。

## 一、5 个经典开篇结构
1. **《画皮》**：日常异常（清晨独行的美女）→主角欲望（色）→外部验证（道士说邪气）→**窗窥真相**（鬼在画皮）——最狠的一击是"亲眼"，不是被叙述
2. **《崂山道士》**：欲望（慕道）一句话立住→仙术奇观→禁忌规则（"归宜洁持，否则不验"）→失败演示（撞墙）
3. **《聂小倩》**：环境钩（最壮丽的寺庙最荒凉）→夜奔女鬼→**规则揭示由"敌方"主动释放**（小倩自述自己被妖物胁迫）——关键情报全由对话分层给出，无旁白铺设定
4. **《鬼吹灯》**：日常民俗物件获得生命（扎纸人骗钱，纸人却活了）→说书式"实有其事"→留白（它为什么活？）
5. **《河神》**：职业即钩子（捞尸人=天天跟死亡打交道）→行规禁忌预热（捞尸忌讳/守夜规矩）→章末点名钩子（"桥下水怪"）

## 二、六个共性规律（最重要）
1. **从"日常异常"切入，异常越小越要命**——恐怖不是怪物闯入日常，是日常裂了一条缝
2. **都有一个"具体物件"承载恐怖**（人皮/墙壁/骨灰/纸人/河漂子）——物件让恐怖可触摸、可破译，给读者锚点
3. **都有"规则/禁忌"感**——世界有自己的法律，你不知道或违反就要付代价
4. **信息分级释放+留白**——先现象→再验证→后真相，真相永远不完整（留白制造越想越怕）
5. **主角欲望先行，欲望就是引路牌**——开篇第一件事亮欲望，恐怖是欲望的代价或试炼
6. **叙述框架制造"实有其事"感**（异史氏曰/家族回忆录/说书人）——用可信度抵消奇幻感

## 三、中式 vs 日式恐怖
- 日式（咒怨/午夜凶铃）：无动机的怨 + 不可逃逸的规则 + 氛围大于事件 + 结局无解
- 中式：**有前因后果——鬼有冤有债、故事可解（超度/报应/真相）；内核是人伦/因果/欲望/规矩；重道德审判与讽刺；仪式感强（冥婚/纸扎/香火/禁忌）**
- 一句话：日式=宇宙规则不可逃逸；中式=**人间因果不可逃逸**——恐怖背后站着人

## 四、给《人间香火录》的落地建议（研究组给的）
- **参照《画皮》开篇结构 + 聂小倩规则揭示 + 河神说书人框架**
- 第一章结构：日常异常（香火突然变旺/神像眼角流油/供品隔夜消失）→主角欲望入场（为救人去求神）→守庙人给出三条禁忌（规则感）→第一次献祭应验（甜头）→**窗窥真相（神在吃人）**→留白收尾（主角已成下一份供品）
- 关键点："神庭"需要一个"道士式知情者"（守庙人/庙祝/上一任祭品）来释放规则
- 窗窥是最可复制的一击：第一章结尾让主角偷看到"神庭吃人"真相（神像张嘴/供品消失/香灰变黑），立刻收笔留白
