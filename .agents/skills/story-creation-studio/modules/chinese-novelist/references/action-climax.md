# 模块: action-climax（chinese-novelist 子模块，按需加载）

### 动作/高潮场面写作专家技法（打斗/追逐/爆发/高潮戏，悬疑奇幻历史类型通用）

- **空间地图先行**：动作开始前 1-2 句交代场地布局（门在左、窗在后、桌子挡路），读者脑中有图才追得上动作；动作中靠'位置参照'维持（'他退到柜台边''她绕过倒下的椅子'），禁止无参照瞬移
- **动作逻辑链**：每个动作 = 意图 + 动作 + 反馈（他抄起酒瓶砸去 → 对方侧头躲过，瓶碎在墙上）；只写'他打了他一拳'是账本不是动作戏；一击必须有一果
- **节奏呼吸**：快慢交替——短句加速（'刀来了。偏头。擦着耳廓过去。'），长句减速（危险逼近时的细节铺陈）；全程高亢会麻木，全程短句会疲劳
- **感官优先级**：动作戏第一感官是'声音与触觉'（刀风/骨节响/铁器擦过地面的拖音/呼吸声），视觉留给关键帧；声音先消失再爆响 = 经典的爆点前呼吸
- **关键帧放大**：全场动作中最狠的一击/最关键的一秒，用慢放写（时间被拉长：'刀刃贴着他颈侧滑过，他数得清那一瞬的呼吸'），其余动作快进
- **体力与代价**：动作进行中写消耗（喘息/汗/手臂发酸/伤口渗血），打完必须有身体代价与余波（瘫坐/手抖/事后才感到疼），无代价的动作戏是 PPT
- **追逐戏节拍**：障碍物逐个消耗体力（翻墙→拐巷→跳窗），节奏递减（越追越慢），视角在追与逃之间切换制造紧迫；'差一点'至少两次（衣角擦过/门在面前关上）
- **高潮戏的情绪支点**：打得再狠也要为'人'打——让读者记得他为什么在这里（救谁/还谁/挡谁）；最高潮处给一句极短的对白或一个眼神，比动作本身更炸
- **打斗中的对白**：喊话短促（一两个字/半句），绝不发表演讲；真正的狠话放在打完之后（余波里的平静威胁 > 打斗中的嘶吼）
- **悬念/惊悚型高潮**：信息不对称（主角不知道对手知道什么）+ 倒计时（'还有三分钟''门锁在倒数'）+ 假安全（刚松口气，灯灭了）
- **动作后的静场**：剧烈之后接极静（只剩呼吸/水滴/远处狗叫），静场是动作戏的句号，也是下一章的呼吸口
