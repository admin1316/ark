# 模块: review-ten-angles（chinese-novelist 子模块——十角度审核法：小说成稿后的系统性审稿流程）

> 来源：v08→v09 实战审核（十次独立角度审核发现 4 逻辑漏洞+2 怪谈违规+文笔/节奏/伏笔/钩子问题）。**长篇/怪谈/悬疑作品成稿后必须走十角度审核**；审核不是"读一遍找错"，而是每次用一个独立身份/标准审一遍。

## 十角度审核清单（每章/每集成稿后逐角度过）

| # | 角度 | 审什么 | 常见问题（实测） |
|---|------|--------|-----------------|
| ① | 叙事逻辑 | 因果链成立？无突兀转折？ | 人物出场无规则锚点/道具转移机制未交代 |
| ② | 怪谈法则 | 恐惧六型落地？无滑向爽文/血腥/解释过度？ | 全知解说过多=恐惧降级为任务说明 |
| ③ | 规则一致性 | 规则前后自洽？无矛盾？ | 规则被角色一次性讲完=细思极恐消失 |
| ④ | 文笔质感 | 克制十法用了几种？有无炫技堆叠？ | 开篇四段连用四种手法=炫技；每法重复 2 次 |
| ⑤ | 章末钩子 | 钩子够强？读者翻页？ | 钩子无铺垫=硬造（线索为零只有结论） |
| ⑥ | 人物弧光 | 主角选择合理？情感立住？ | 选择过于自觉=不像被卷入者；"悟"代"怕" |
| ⑦ | 节奏篇幅 | 信息密度？拖沓/仓促？ | 前两节铺垫密度过低=慢热；问答原地踏步 |
| ⑧ | 伏笔埋设 | 伏笔埋了？会忘收？ | 单点伏笔密度超标（三重堆叠=太干净）；无铺垫伏笔=回收风险高 |
| ⑨ | 对话质量 | 对话克制有力？无废话/解说腔？ | 同一信息层级问答连用两次=原地踏步 |
| ⑩ | 改编可行 | 能拆漫剧画格？每格有画面？ | 心理描写无法视觉化=改编时删 |

## 审核执行纪律

1. **每次审核用一个独立身份**（逻辑学家/怪谈守则执行者/审稿编辑/漫剧分镜师）——不同身份看到的问题不同
2. **每条问题给三件套**：问题定位（引用原文）+ 具体问题 + 修改建议——不许只给"感觉不对"
3. **审核后必须修复清单化**：汇总成"必须修复的 N 条"，逐条修复，修复后逐条验证（OK/未达标）
4. **修复时保留优点**：先列出"保留清单"（v08 的优点：船是第一个知觉/指甲剪得齐/船板是温的），修复只动问题不伤优点
5. **十角度可以分组跑**（①-③逻辑组/④-⑥文笔组/⑦-⑩结构组），每组一次审核

## 实测发现的高频问题（v08→v09 案例库）

- **怪谈最大杀手 = 解释过度**：白衣女子把"酒=香=命、续香=接灯、续到渡口"全讲完 → 恐惧从"规则压迫"降级为"任务说明"。修复：解说减半，只留最必要规则，后果留白
- **逻辑最大杀手 = 无规则锚点**：白衣女子"想出现就出现" → 修复：第二声钟落下的瞬间她已在船头（"像她一直站在那里，只是这一刻才被钟声允许被看见"）
- **文笔最大杀手 = 手法炫技**：克制十法开篇四段连用 → 修复：开篇第一段保持朴素，每法只留一处
- **钩子最大杀手 = 零铺垫硬造**："三个人的心跳"突然出现 → 修复：船板留两道座痕+白衣说"这盏灯换过好几任主人"
- **节奏最大杀手 = 慢热**：碗在第 1200 字才出现 → 修复：碗提前到第一节末尾（前 1/5 内必须出现第一个异常物）

## 一句话记忆

**审核不是找错，是"每次用一个身份重新读一遍"**——十个身份读过十遍，问题自然浮出来；修复时"保优点、动问题、逐条验"。
