# 模块: pov-info（chinese-novelist 子模块，按需加载）

### 视角与信息控制（POV 选择/切换纪律/信息差管理——悬疑与长篇的叙事武器）

- **视角四型（开篇前选定，全书遵守）**：第一人称（最强代入+信息天然受限——'我'不知道的事读者不知道，悬疑首选）· 第三人称限知（跟随一个角色的感官，可写他人外貌但不可写他人内心）· 第三人称全知（可写多人内心，悬疑慎用——知道太多会泄底）· 第二人称（实验性，短篇可用）；限知视角下禁止写视角角色的认知盲区之外（他没看见的场面不能写）
- **信息差管理（悬疑/悬念的核心机制）**：三种信息差——读者>角色（希区柯克炸弹理论：桌下有炸弹，角色不知道——悬念）；角色>读者（秘密被角色藏着——谜团）；角色A>角色B（对戏时的张力来源）；每章开篇明确'当前谁比谁多知道什么'，章末检查信息差是否被利用（无信息差变化的章节=浪费章）
- **视角切换纪律（多视角小说）**：视角切换只在'章/节'边界（禁止段内跳视角）；切换时第一句必须有'视角标记'（人名+感官动词：'陈sir推开面馆的门，闻到……'）；切换频率：每章 1 个主视角+必要时 1 个次视角；切换目的必须是'信息增量'（让读者知道单视角看不到的事），为切换而切换=散
- **限知下的写作技巧**：不写'他看不见的'（可用'声音/气味/间接信息'暗示）；内心独白只能写给视角角色；其他角色的表情通过视角角色的解读呈现（'她笑了一下，但眼睛没动——他见过这种笑'）；视角角色的感官偏差是角色塑造（近视的/嗅觉灵敏的/总是先看手的角色，看到的重点不同）
- **视角与钩子的配合**：章末钩子常是'视角盲区被打破'（视角角色突然意识到自己被骗/看到不该看的）；反转的冲击力=信息差的落差（读者以为知道全部，反转揭示'视角角色本身被骗'）——反转收的伏笔与信息差配合使用
- **与改编的衔接**：视角决定'信息给观众的时机'——改编漫剧/影视时，限知视角角色的认知=观众认知的基线；多视角小说改编时按'信息增量'重组（保留信息差结构，重组呈现顺序）
