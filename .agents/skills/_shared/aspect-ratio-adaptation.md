# 画幅适配标准（横屏/竖屏双画幅，任意画幅都能出专家级）

> 用途：分镜/画格/执行稿/生图提示词必须按目标画幅适配——横屏与竖屏是**两套构图语言**，不是同构图裁切。同时支持"安全区设计"（一版双出：核心信息居中，横竖可裁）。

## 1. 竖屏（9:16 / 3:4 手机优先）

- **纵向构图优先**：人物立幅（全身纵深）、视线上下流动、纵向引导线（楼梯/高楼/瀑布）
- **信息布局**：重要信息放中上 1/3（拇指区=安全区，用户拇指不遮挡）；标题/文字靠下或顶部
- **景别倾向**：特写/中近景为主（小画幅放不下全景信息）；全景用于环境建立但压缩信息量
- **构图纪律**：单焦点大主体（占画幅 40-60%）；左右留白少（窄画幅易挤）；对话用上下分层（A 上 B 下）或斜分
- **节奏**：信息密度高（一屏=一信息点）；快速切换（8 次/分钟适配）

## 2. 横屏（16:9 标准 / 2.35:1 电影宽银幕）

- **横向构图优先**：地平线定位（上 1/3 天空/下 1/3 地面压迫）、横向引导线（道路/队列/光影带）、左右空间关系
- **信息布局**：主体偏心三分线（左或右 1/3），对侧留负空间；标题区左右皆可
- **景别倾向**：全景/中全景为主（宽画幅承载环境与关系）；特写用于聚焦
- **构图纪律**：双人对峙用分列（各占 1/3 中留缝）；群像横向展开（三角/波浪布局）；大场面横向纵深
- **节奏**：信息密度中（一屏可含环境+人物+关系）；长镜头更自然

## 3. 宽银幕电影画幅（2.35:1 / 2.39:1）

- 横向构图+上下空间被裁（字幕区预留）
- 史诗感来源：大负空间+横向长引导线+人物置于地平线
- 适配：变形宽银幕镜头（Anamorphic）横向光晕是画幅语言的一部分

## 4. 安全区与一版双出（横竖双版本）

- **安全区设计**：核心信息（人脸/关键道具/文字）放在画面中央 60% 区域（横 16:9 裁成竖 9:16 时两端 20% 可舍）
- **一版双出流程**：先设计竖版主体构图（信息层级），再扩展横版左右空间（环境延伸/次信息），保证裁切后核心不丢
- **禁忌**：把横版直接裁成竖版（构图失衡）；把竖版拉宽（变形）

## 5. 各环节适配

- **分镜表**：画幅字段（9:16/16:9/2.35:1）写在表头；景别/构图按画幅选
- **画格**：竖屏=纵向构图优先+拇指区；横屏=横向引导线+地平线
- **执行稿**：画幅字段入头部；运镜按画幅（竖屏纵向摇移/横屏横向摇移）
- **生图提示词**：画幅写进提示词开头（'竖屏 9:16'/'横屏 16:9'/'2.35:1 宽银幕'）；构图词按画幅选（竖=纵向/横=横向）

## 6. 转换检查（横↔竖）

- 同一内容双版本时：核心信息在安全区？景别是否按画幅重选（不是硬裁）？构图语言是否切换（纵→横）？
- 字幕/标题位是否按画幅放置？焦点是否仍唯一？
