# Context Budget Test（上下文预算测试）

验证：单次任务加载的上下文是否在预算内。

## 预算标准

| 路径 | 预算 | 说明 |
|------|------|------|
| 热路径（主文件） | ≤80 行 | SKILL.md |
| 热路径（常用模块） | ≤160 行 | 1-2 个技法模块 |
| 按需路径（深档小节） | ≤100 行 | 深档只读对应节 |
| 单任务总加载 | ≤350 行 | 主文件+模块+深档小节 |

## 判定标准

- 单任务 ≤350 行（主文件+模块+深档小节）
- 深档全文（414 行级）**不计入**默认预算（按需才读）
- 超预算时：检查是否误加载了无关模块或深档全文
