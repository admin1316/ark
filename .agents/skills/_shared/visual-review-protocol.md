# 视觉评审协议（Visual Review Protocol）

> 用途：当有**视觉模型**（Claude/GPT-4o/生图工具自带点评）可看图时，按本协议逐项评审生成图——把技能库的行业标准变成视觉模型的检查清单。
> 权限：本技能库的模型若为纯文本（如 deepseek-flash），只能做像素级客观分析（见文末），审美判断必须交给视觉模型+本协议。

## 第 0 步：主体分类（评审前必做——人和物标准不同，禁止串用）

收到图片先判定主体类型，再选对应标准：

- **真人（实拍/写实角色）**：用真人标准——皮肤毛孔/次表面散射/微表情自然度/恐怖谷/塑料皮肤=缺陷
- **神像/雕塑/雕像（金身/泥塑/木雕/石像/彩绘）**：用雕塑工艺标准——材质符合设定（漆金/鎏金/彩绘/做旧）是**优点**；"光滑瓷面"对金身是合理的，不算 AI 缺陷；禁评"塑料感/恐怖谷/无毛孔"（那是真人标准）；改查：鎏金是否均匀/彩绘是否精细/磨损做旧是否自然/形体比例是否符合传统造像
- **道具/物品/食物**：按材质物理层标准——木质（纹理/包浆）、金属（IOR/氧化）、食物（油脂/果霜/汁液）、布料（织理/垂坠）；查材质是否可信，不套人物标准
- **动物/生物**：查解剖结构/毛发羽毛/眼神生命力
- **纯环境/空镜**：查构图/光影/氛围/叙事锚点

**判定错误示例**：用"无毛孔/塑料感"评财神金身=错误（金身本来就该有漆面感）；用"雕塑感"评真人=错误。

## 评审流程（视觉模型逐项执行）

收到图片先完成第 0 步分类，再按以下 7 项逐项检查，每项给"通过/不通过+证据+修改建议"（标准随主体类型调整）：

### 1. 亮度锚定（最高优先级）
- 主体（人脸/关键物）是否处于中间调、清晰可辨？是否淹没在阴影中？
- 死黑占比是否 ≤10% 且只在角落/光源背面？画面是否整体过暗？
- 证据：肉眼观察主体亮度区与角落暗区比例

### 2. 构图（对照八大法则）
- 用了什么构图法则（三分/框架/引导线/负空间/对称）？焦点在哪？观众第一眼落点是否是戏核？
- 地平线/消失点是否正确？有无透视错误（平行线不汇聚/人物悬空）？
- 证据：描述构图结构 + 指出焦点位置

### 3. 角色一致性
- 人物是否符合角色卡锚点（发型/标志物/服装/伤疤）？
- 群像是否防克隆（面孔/姿态/服饰是否重复）？
- 证据：对比锚点逐项核对 + 检查群像差异

### 4. 表情与表演
- 面部是否自然（无恐怖谷/僵硬/塑料感）？表情是否单一脸谱化？
- 是否冻结在单一情绪瞬间（无时间推进感）？
- 证据：描述眉眼嘴角状态 + 判断真实度

### 5. 光学与实拍证据
- 有无真实照片证据（颗粒/暗角/紫边/眩光/跑焦）？还是干净 CG 感？
- 光影物理是否可信（光源方向一致/反射带色/多色温混光合理）？
- 证据：指出 2-3 处光学特征 + 光影逻辑

### 6. 色彩与调色
- 主色/强调色是否明确？唯一暖色是否成立？肤色是否自然暖调？
- 有无 AI 味色彩（高饱和/青橙割裂/塑料感）？
- 证据：描述色板构成 + 指出问题色区

### 7. 文字与细节缺陷
- 文字/数字是否乱码？手指数/牙齿/肢体是否变形？
- 有无多余肢体/畸变/重复元素/水印？
- 证据：指出具体位置

### 8. 空间与坐标（AI 生图高频失败项，必查）
- 关键元素位置是否符合提示词预定坐标（±10%）？——船/人/门/光柱各在画面的哪个区域？
- 有无"船挤窄条/人船分离/群像挤成竖线/主体贴边出画"？
- 有无明确的中间空域（视线通道）？还是元素挤成一团？
- 证据：指出每个关键元素的框位置（x/y 范围）+ 与预定坐标的偏差

### 9. 物理连接（防"AI 拼贴感"）
- 光是否有落点（光斑/投影/倒影承接）？还是悬浮无根？
- 人物是否有来处/方向线索？还是凭空出现？
- 光源是否有可见来源（灯/窗/天光）？还是无来源发光？
- 证据：指出连接点或断裂点位置

## 像素级客观分析（无视觉模型时的兜底，也是视觉模型的前置客观据）

用 `scripts/pixel-analysis.py <图>` 分析（已内置量化判定），核心标准：
- 中央 60% 区域平均亮度 **≥25%**（低于 25 = 主体淉没在阴影；25-30 = 暗场景可接受但偏暗）——这是“暗部太暗”投诉的核心指标，全局平均亮度低不代表主体暗，必须看中央区
- 中央死黑 ≤10%；角落死黑 ≤10%（角落是死黑唯一允许区）
- 最亮 5% 像素 **≥150（必须有高光点）**，否则画面发闷
- 平均亮度 40-60% 正常、<20% 过暗；暗部占比 >40% 过暗；暖色占比 <2% 无唯一暖色
- 判定依据：对照亮度锚定协议（死黑 ≤10%/主体中间调≥25%/高光点≥150/暗词 ≤3）

## 使用场景

- 生成图后：先像素分析（快速客观），再交视觉模型按 7 项评审（审美判定）
- 分镜画格/关键帧/海报验收：用本协议替代"人眼质检"的第一步
- 与成片质检链路配合：本协议=画格/关键帧层；成片质检=视频层
