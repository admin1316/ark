# 真人微表情与连续表演合同

本合同供小说改编、角色资产、短剧剧本、导演分镜、可视画格、AI 视频执行稿和电影关键帧共同使用。目标是把“悲伤、害怕、崩溃”等抽象词，拆成在限定时长内可看见、可表演、可剪辑、可生成的连续变化。

## 一、总原则

1. **细节密度不等于情绪强度。** 可以把克制写得极细，不必让所有人物都流泪、哭喊或失控。
2. **先有刺激，后有反应。** 任何表情变化都要写明触发物、认知延迟、非自主微反应、主动压制、决定、动作结果和余波。
3. **同一瞬间只保留一个主导情绪。** 温柔、慌乱、恐惧、严肃、崩溃不得在同一帧同时到达峰值；必须分阶段发生。
4. **表情服从人物目标。** 角色是在努力完成一件事，不是在向镜头展示情绪。父亲压住眼泪保护孩子，与角色放声痛哭，是两种不同表演任务。
5. **只写可见、可听、可执行的证据。** 不写“内心翻涌”，改写成视线停顿、呼吸中断、眼睑张力、下颌锁紧、手指失控等。
6. **单帧只冻结一个阶段。** 一张关键帧不能同时表现“浅笑→慌乱→蓄泪→落泪→嚎哭”；连续变化必须拆成多个画格或视频时间段。
7. **表演不能破坏连续性。** 眨眼、泪痕、湿发、鼻红、呼吸强度、嘴唇状态和视线方向都属于角色状态，跨镜只能按因果增减。
8. **逐镜强制执行。** 凡画面中有人物可读，每一个镜头都必须有与该场景刺激、人物目标、景别和时长相匹配的表演状态；不得只给“关键特写”写表情、其余镜头让人物恢复成中性立绘。
9. **模板只能作为词库，不能整段复制。** 同一人物在不同场景、不同镜头中的眼神、眉眼、口鼻、呼吸、手势和压制方式，必须由当下刺激重新推导；不得把“隐忍含泪”或“崩溃痛哭”原文粘贴到所有人物身上。

## 二、核心万能写作公式

### 1. 基础公式

`镜头规格 + 人物身份锚 + 当前目标 + 场景刺激 + 分层生理反应（眼神 / 眉额 / 嘴唇下颌 / 鼻翼呼吸声音 / 头颈肩 / 手与重心）+ 抑制动作 + 情绪结果 + 时间与连续性约束 + 光线材质`

禁止只写“人物很难过、人物很生气、人物很害怕”。必须改写成观众可看见或听见的证据。例如：

- 抽象：`人物很难过。`
- 可执行：`下眼睑先泛红，眼底泪膜在一次被延迟的眨眼后增厚；嘴唇压紧，鼻翼随被截短的呼气轻微翕动，视线仍锁住对方，不让泪越过下睑。`

### 2. 动态镜头三段式

每个含表演的动态镜头至少写清以下三段；短镜头可压缩帧数，但不能删掉因果：

1. **初始克制：** 给出进入镜头时的基线、视线目标、呼吸和肌肉张力。
2. **酝酿过渡：** 刺激抵达后，眼球/耳朵先行，泪膜、鼻翼、喉结、下颌、手指或重心逐步泄露情绪。
3. **释放或决定：** 情绪不是必须哭喊；它可以转化为一句命令、一次急停、一次伸手、一次退缩或一滴终于落下的泪，并保留余波到切点。

### 3. 景别适配

“每镜都有表演”不等于“每镜都写毛孔和血丝”。按信息尺度填写：

| 景别/镜头类型 | 必须写的表演信息 | 不应强塞的信息 |
|---|---|---|
| 极大特写/大特写 | 眼球焦点、上下眼睑、眨眼帧数、泪膜、眉间、鼻翼、唇与下颌、皮肤与水分 | 大幅走位、复杂全身动作 |
| 近景/中近景 | 面部区域 + 喉结/呼吸 + 肩颈 + 手部小动作 + 对手眼线 | 无法读清的毛孔级细节堆砌 |
| 中景/全景 | 重心、步态、肩胛、胸腹呼吸、手臂准备、停顿、人与人的距离 | 血丝、细泪线、唇瓣微颤等不可读细节 |
| 背影/遮挡镜 | 耳朵先动、头颈准备、肩胛、手指、呼吸、衣料受力 | 虚构观众看不见的正面表情 |
| 手/脚/道具插入 | 指尖、握力、脚底受力、材质形变、雨/烟/液体反馈 | 面部情绪清单 |
| 纯空镜 | 环境的物理状态、声场和即将影响人物的刺激 | 不存在的人物微表情 |

### 4. 动态质量短语的正确用法

可按需使用：`轻微、微妙、几乎不可见、循序渐进、缓慢流转、面部肌理自然、皮肤纹理真实、细微呼吸起伏、人物面部特征稳定、五官无夸张扭曲`。

“一镜到底连贯动态”只约束**当前单个镜头内部**；有明确分镜剪辑时，必须写成“镜内连续、切点干净、跨镜状态连续”，不得要求整场一镜到底而抹掉已设计的剪辑。

## 三、七阶段表演状态机

按剧情需要选用，不要求每场都走到最后一级：

| 阶段 | 功能 | 可见证据 |
|---|---|---|
| P0 基线 | 交代角色进入刺激前的身体状态 | 呼吸频率、眼神落点、肩颈张力、嘴唇开合、手部姿态 |
| P1 刺激抵达 | 声音、人物、危险或信息进入感官 | 耳朵/眼球先动，眨眼中断，呼吸停顿，瞳孔与焦点变化 |
| P2 非自主微反应 | 身体比理智更早泄露情绪 | 下眼睑颤动、内眉抬起、鼻翼轻扩、喉结吞咽、指尖收紧 |
| P3 主动压制 | 角色试图不让情绪失控 | 下颌锁紧、嘴角压平、眨眼变少、视线重新锁定、呼气被截短 |
| P4 决定与行动 | 情绪转化成可改变剧情的行为 | 说出命令、伸手、后退、急停、转身、遮掩、推开 |
| P5 防线破口 | 压制失败，但仍未完全崩溃 | 泪膜越过下睑、一次破音、嘴唇颤动、呼吸变乱、视线短暂涣散 |
| P6 完整失守 | 只有剧情确实到达崩溃峰值时使用 | 连续落泪、眉额牵动、鼻翼与胸腹大幅呼吸、哭声失去稳定控制 |
| P7 余波 | 高潮之后的身体残留 | 抽气、泪痕、鼻红、喉部疼痛、肌肉小幅震颤、目光无法立即恢复 |

`P6` 不是“更电影”的默认答案。没有足够铺垫、时间和角色动机时，最高停在 `P3–P5` 通常更可信。

## 四、逐镜表演合同必填字段

对每个有人物可读的镜头逐角色填写；纯空镜和道具插入改填环境/材质反应：

1. `trigger`：触发物及其银幕位置/声音方向。
2. `duration`：起止时间或帧号；24fps 项目同时写帧数。
3. `gaze`：视线目标、转移方向、是否越过对方看危险。
4. `eyes`：睁合量、眼睑张力、眨眼、泪膜、眼白与血丝变化。
5. `brows_forehead`：内外眉、眉间距、额纹是否形成和如何消退。
6. `mouth_jaw`：嘴角、上下唇、下颌、咬肌、吞咽、口型幅度。
7. `nose_breath_voice`：鼻翼、吸呼气、胸腹起伏、发声位置、破音与停顿。
8. `head_neck_shoulders`：头颈准备、肩胛、重心与疼痛/惯性反馈。
9. `hands_body`：手指、手腕、躯干及目标驱动的动作。
10. `fluids_materials`：雨水、汗、泪、鼻水、唾液、湿发和衣物的物理状态；只在镜头能读到且剧情需要时写。
11. `suppression`：角色正在压住什么，压制动作是什么。
12. `exit_condition`：什么动作、台词、剪辑点或新刺激结束本阶段。
13. `entry_state`：从上一镜继承的眼红、泪痕、湿发、呼吸、疼痛、视线和手部状态。
14. `shot_scale_filter`：本景别真正能被看见的表演信息；主动删除超出信息尺度的细节。
15. `negative_performance`：本镜禁止出现的笑、哭、瞪眼、张嘴、看镜头、随机眨眼、状态归零等错误。

## 五、时间容量参考（24fps）

这些是制作安全范围，不是机械定律：

- 单次眼球先行转移：4–8帧。
- 轻微认知延迟：3–7帧。
- 一次自然眨眼：4–8帧；悲伤压制时可延迟眨眼，但不能完全没有生理反应。
- 下眼睑或嘴角一次微颤：4–10帧。
- 吞咽、下颌重新锁紧：8–16帧。
- 泪膜从可见到越过下睑：至少24–48帧；若无铺垫不得一切镜就满脸泪。
- 单滴泪沿脸颊下行：至少24–72帧，受脸角度、雨和重力影响。
- 从克制到完整哭喊：至少2–4秒，并需要前置刺激与压制失败。
- 情绪高潮后的余波：至少12–48帧；不能台词结束同帧恢复正常。

## 六、强度标尺

| 等级 | 屏幕表现 | 适用 |
|---|---|---|
| E0 | 中性基线，只有呼吸和自然眨眼 | 建立、过渡 |
| E1 | 一处微反应可见，仍完全可控 | 发现、疑问 |
| E2 | 两到三处生理信号，角色主动压制 | 久别重逢、隐忧 |
| E3 | 泪膜/破音/动作迟滞出现，目标仍清楚 | 保护、告别、选择 |
| E4 | 单滴泪或短暂失声，行为开始受情绪干扰 | 失去、背叛、濒临崩溃 |
| E5 | 连续哭泣或哭喊，呼吸和面部控制明显失守 | 真正情绪决堤 |

若用户给出“眼红、血丝、浅笑、慌乱、泪落、清涕、嘶吼”等一整串要求，先判定它属于 `E5/P6–P7`，再按时间轴拆分。不得把词表原样塞进一个静帧或3秒镜头。

## 七、五大类微表情词库与场景化规则

下列只是母型。实际输出必须先指定 `触发、对象、目标、遮掩、强度、时长、退出条件`，再从母型中选取可见证据。

| 情绪母型 | 常用可见证据 | 必须避免 |
|---|---|---|
| 喜悦/宠溺/狡黠 | 眼睑放松或眼尾轻提、单侧嘴角短暂发力、苹果肌轻抬、肩颈卸力、目光停留时间增加 | 每个人都露齿笑、双眉同时高抬、笑容切镜归零 |
| 悲伤/委屈/苦笑 | 内眉上提或向内收、泪膜渐厚、眨眼延迟、嘴唇压紧或短颤、鼻翼与呼吸失序、手部退缩 | 未铺垫就满脸泪、苦笑和嚎哭同帧、把清涕当高级感装饰 |
| 冷怒/暴怒/烦躁 | 眉骨下压、咬肌与下颌绷紧、眼神锁定或拒绝对视、鼻翼扩张、呼吸短促、握力增加 | 反派式持续瞪眼、所有愤怒都大张嘴、无决定动作的空吼 |
| 错愕/心虚/恐慌 | 目光定格或躲闪、眨眼中断、瞳孔/焦点变化、呼吸停顿、头颈后撤、指尖摩挲 | 眼球夸张放大、五官突变、刺激未出现就先害怕 |
| 疏离/欲言又止/复杂内心 | 眼睑下垂、视线侧下、嘴唇开后再合、喉结吞咽、肩膀收紧、手势起而复止 | 用旁白替代行为、多个矛盾情绪同时达到峰值 |

### 场景化推导句式

`因为[具体刺激]从[方向/距离]抵达，角色为了[当前目标]先压住[真实情绪]；[非自主区域]在[帧数]内泄露反应，随后通过[下颌/视线/呼吸/手势]重新取得控制，最终做出[改变剧情的动作]，并把[泪痕/呼吸/肌肉余波]带入下一镜。`

## 八、不同技能的输出边界

### 小说正文

只选少量最有叙事价值的身体细节，嵌入动作和感官，不写解剖清单。保留省略，让读者自己完成情绪。

### 角色资产/表演圣经

按人物输出基线表情、压制习惯、哭泣方式、恐惧方式、愤怒方式、常见视线和声音变化。此文档独立于角色 JSON，避免破坏既有 schema。

### 短剧剧本

每个节拍写 `触发 → 可见反应 → 压制 → 台词/动作 → 结果 → 余波`。每个有人物的镜头都要有表演状态，不能只在情绪高潮写一次。把复杂情绪拆成多个可拍的动作段。

### 导演分镜

每镜逐角色写清主导阶段、进入状态、表情/身体触发、持续时间、动作结果、余波、反应镜头与剪辑理由。只有特写/近景承载精细面部信息；全景主要读身体、距离和空间。任何人物镜头若没有表演字段，分镜不得通过。

### 可视化分镜

一个画格只冻结一个关键姿势/表情阶段。需要变化时使用同一镜号的 `-A/-B/-C` 子画格，并保持身份、轴线、光线、泪痕和道具状态连续。每个画格必须带 `performance_state_id` 与上一/下一画格状态指针。

### AI 视频执行稿

按时间段写动作与表情生命周期。每个人物镜头都要输出 `entry_state → micro_reaction → suppression → action/release → residual`。把人物运动、面部表演、摄影机运动、VFX和声音分层；禁止同一时间窗要求互相冲突的表情。统一负面约束必须包含身份稳定、五官不扭曲、无随机眨眼、无口型漂移、无跨镜情绪归零。

### 单张电影关键帧

只描述冻结瞬间：明确眼、眉、嘴、呼吸的“当前状态”，删掉“缓慢完成、逐渐、随后、最后、反复”等时间推进词。若用户要完整递进，先拆成多张关键帧。

## 九、E5崩溃戏的合规拆分模板

仅当剧情需要完整失守时使用：

1. `A 克制`：眼白轻红、泪膜形成、嘴唇压住、呼吸仍能控制。
2. `B 破口`：视线躲闪后返回，内眉收紧，一次眨眼使第一滴泪越过下睑。
3. `C 失序`：鼻翼加速、下颌与脸颊抽动、台词破音、泪水连续。
4. `D 决堤`：嘴部张开哭喊、眉额动态纹理加深、胸腹呼吸大幅起伏。
5. `E 余波`：声音破碎、抽气、泪痕和鼻红保留，肌肉不能立刻归零。

清涕、唾液丝或嘴角水丝属于极强生理写实细节，只在剧情、景别和分级允许且确有必要时使用；不得当作“高级感”装饰。

## 十、交付前检查

- [ ] 触发是否先于反应？
- [ ] 每个时间窗是否只有一个主导情绪？
- [ ] 表情变化是否有足够帧数可读？
- [ ] 近景写面部，全景写身体与空间，没有信息错配？
- [ ] 泪、雨、汗、鼻红和湿发是否跨镜连续？
- [ ] 台词、呼吸和口型是否能在时长内自然完成？
- [ ] 静帧是否只冻结一个阶段？
- [ ] 细节是否服务人物目标，而非堆砌痛苦词汇？
- [ ] 每一个人物可读镜头是否都有独立、场景化的表演状态，而非复制同一模板？
- [ ] 全景、背影、手脚插入和空镜是否使用了与信息尺度相符的身体/材质语言？
