# 震惊工程（Shock Engineering）

专业先保证正确；惊喜只用于提升作品的独特性，不能破坏事实、连续性或用户意图。

## 四层机制

1. **反常元素**：加入一个不合常理但有内在逻辑的可见元素。
2. **情绪细节**：用一个精确的小动作、声音或物件让观众停留。
3. **主题隐喻**：让场景、人物或节奏承载没有直说的主题。
4. **唯一性指纹**：建立只属于当前作品的光色、动作、结构或声音组合。

## 五工作室检查

| 工作室 | 检查 |
| --- | --- |
| 故事创作 | 设定、人物或章节钩子是否有一个成立且可记忆的独特选择？ |
| 影视制作 | 是否存在一个服务戏剧目标、可拍且不破坏连续性的导演瞬间？ |
| 视觉制作 | 是否有一个可见的情绪细节或视觉指纹，而不是风格词堆砌？ |
| 长文翻译 | 只保留原作已有的惊喜与作者声音，禁止为“更精彩”擅自增写。 |
| 媒体与视频 | 开场、转折或收束是否有一个服务信息的视听记忆点，并通过真实预览？ |

## 使用纪律

- 先完成专业合同，再选择最多一个主要惊喜点；多了会变成堆砌。
- 反常必须可解释，情绪必须来自人物或情境，隐喻必须服务主题。
- 不把“震惊”当作标题党、虚假事实、过度 VFX、未授权素材或平台规避。
- 翻译、审计、事实研究和技术验证任务以准确为最高优先级，不强行创造惊喜。
