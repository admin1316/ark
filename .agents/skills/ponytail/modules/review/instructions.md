# 当前改动精简审查

只审查当前 diff 中不必要的复杂度，不代替正确性、安全与性能审查，也不直接修改文件。

逐项输出：`文件:行号: 标签: 可删除或收缩内容。替代方案。`

标签：

- `delete`：死代码、重复实现或无调用价值的灵活性；不需要替代。
- `stdlib`：手写了标准库已有能力；写明 API。
- `native`：自定义层或依赖重复了平台原生能力；写明原生组件。
- `yagni`：单实现接口、单产品工厂、无人设置的配置。
- `shrink`：逻辑不变但可在同一 owner 内明显缩短。

按风险和可删除行数排序；没有发现时仅报告“当前改动已经精简”。不得把必要 contract、信任边界、安全、数据保护和无障碍当作冗余。
