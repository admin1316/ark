# Ark Ponytail 帮助

- `/ponytail` 或 `/ponytail full`：当前代码任务采用最小完整实现。
- `/ponytail lite`：照常实现，同时指出一个更精简选项。
- `/ponytail ultra`：删除优先，挑战没有证据的需求。
- `/ponytail review`：只读检查当前 diff 的过度工程。
- `/ponytail audit`：只读审计整个仓库。
- `/ponytail debt`：列出 `ponytail:` 债务标记。
- `/ponytail gain`：显示上游公开 benchmark，不冒充 Ark 实测。

所有模式都不得删减安全、数据保护、错误处理、无障碍或用户明确要求；非平凡修改仍需测试和真实行为验收。
