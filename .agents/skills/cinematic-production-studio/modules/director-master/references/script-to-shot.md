# 模块: script-to-shot（director-master 子模块，按需加载）

### 剧本→分镜衔接技法（短剧/漫剧剧本转九列分镜的转换规则）

- **剧本元素映射**：`△动作` → 画面内容（拆成可见动作序列）；`角色名（表情）：台词` → 声音列对白 + 画面内容表演调度；`OS` → 旁白/内心声（标在声音列）；`【视觉焦点】` → 该镜头用特写/关键道具（直接落为镜头设计）；`【音效】` → 声音列
- **场景标题拆镜**：一个场景标题下的动作段落按'戏剧节拍'拆镜（每个独立动作/反应/视线变化=一个镜头），不是按自然段拆
- **对白→镜头**：一段对话拆正反打（说话者近景+听者反应）；长对白拆成'说话+反应'交替，反应镜头必须有信息（表情变化/视线偏移/小动作）
- **OS/旁白处理**：OS 处配'主观镜头'或'人物微表情特写'（观众需要看到说话的人）；纯旁白段落用环境空镜承接
- **漫剧适配**：每场景 4-6 格节奏（剧本 [格x/6] 标注直接对应分镜表分组）；一格=一个分镜（或一个分镜组）；漫剧分镜保留九列但时长按格节奏缩放
- **真人实拍适配（真人短剧/电影镜，九列备注列必标'影像质感'）**：每镜备注加影像基底（Kodak Vision3 250D/500T/Fuji Eterna/ARRI Alexa 风格）· 颗粒倾向（细/粗/暗部颗粒）· 光学特征（球面/变形宽银幕/老镜头）；实拍镜的曝光逻辑（高光溢出只给光源/暗部深灰层次/死黑 ≤10% 只在角落）写进画面内容列；纯漫剧/动画镜不适用（走风格化），真人镜缺影像质感的备注=分镜不完整
- **亮度锚定（防'成片太暗'，画面内容列必写）**：暗环境+亮主体——每镜画面内容先写主体亮度（'面部中间调清晰明亮'）再写环境（'环境深灰层次'）；禁止只写环境暗词；死黑 ≤10% 只在角落/光源背面；连续暗场镜 ≤2 个（第 3 个暗场镜前必须插入亮场镜或提亮主体）；亮度档标注（明亮/柔和/偏暗，默认柔和偏亮）写进备注列
- **钩子衔接**：剧本 【本集钩子】 → 分镜表最后一镜必须承担钩子功能（悬念定格/特写疑点/声音突袭）

### 镜头职能与空镜设计（九列分镜的镜头职能标注——该场景时场景，该人物时人物）

- **镜头三职能（分镜表每镜在'叙事目的'列首字标注：场景/人物/人景）**：场景镜头（空镜/环境/奇观，无人或人极小——交代空间/时间流逝/情绪外化/节奏呼吸/伏笔埋设）；人物镜头（表演主体：情绪/冲突/反应）；人景镜头（人与环境同框，大小对比=情绪）
- **空镜合法性（专业常态，不是'没人'就没用）**：一段戏空镜占比 15-30% 为正常；空镜必承担一项叙事义务——新场景第一镜交代空间（地理/时代/氛围）· 时间流逝（日转夜/季节/钟表）· 情绪外化（暴雨=内心/废墟=创伤/天晴=释然）· 节奏呼吸（大情绪后的静默空镜）· 伏笔埋设（墙上照片/桌上信/远景人影）；无信息空镜=废镜删
- **空镜的'贴人'用法（专业技巧）**：人物上场前的空镜=引子（门口空镜→门开→人进）；人物离场后的空镜=余韵（空椅/熄灯/风卷窗帘）；空镜转场=时空跳跃的标点（夜城空镜→晨屋空镜）；情绪高峰前的空镜=蓄力（决战前天空/暴风雨前海面）
- **人景镜的'对比即情绪'**：人在奇观中的大小=情绪（天宫前渺小=敬畏/决然；废墟中站立=幸存；人群中被淹没=孤独）；人景镜给'环境触发+人物反应'成对（雷声→抬眼/门开→握拳/神光→闭眼）
- **职能分配节奏（分镜表检查）**：场景→人物→人景→场景→人物的呼吸节奏；全片全人物镜=疲惫（无喘息），全片全场景镜=空虚（无情感）；大场面（奇观）镜后必接人物反应镜（观众需要一张脸确认情绪）；空镜密度按类型调：文艺片高（30%+），短剧低（10-15%，节奏快），类型片中等（20%）

### 分镜表渲染规格与衔接字段（九列之外的必填扩展，让文字分镜可直接进执行阶段）

- **扩展字段（每镜在备注/新增列中给出，共 6 项）**：管线（UE5.3 Lumen 实时 / Redshift RT 离线 / Octane X / V-Ray 6，按镜头职责选：跟拍大场景→Lumen，人脸质感→Redshift，爆点光谱→Octane，光照验证→V-Ray）· 物理相机（焦距/T/快门 180° 开角/ISO/白平衡+曝光，参数写死，字段名对照 short-drama-ai-suite 可执行参数层：UE CineCamera 用 FocalLength/Aperture/ShutterSpeed/ISO，Redshift Camera 用 Focal Length/Aperture/Shutter Speed/ISO/White Balance，V-Ray Physical Camera 用 f-number/shutter speed/ISO/white balance，禁止发明字段名）· 转场（hard-cut/dissolve/match-cut/whip-pan/blackout + 理由）· 出点帧（本镜末帧画面状态，可复制进下一镜提示词）· 剪辑点（动作中剪/动作后剪 + 理由）· 音画衔接（声音先入/画面先入/BGM 跨镜/静默）
- **一镜一事**：每镜只承担一个事件（驶入/称量/亮灯/横移/心跳）；事件必须拆镜，4 秒塞 6 节点 = 指数级抽卡失败；单事件 = 单锚点 = 低失败率
- **主光保底**：人脸镜给侧顶 45° 主光（五官可辨）+ 金边轮廓光；禁止强逆光人脸；微表情最小集（蹙眉+睫毛轻颤）
- **固定机位优先**：光位变化替代微妙推近；必须跟拍时 Spline 路径 + ease-in-out 速度曲线 + 相机与主体速度同步（追逐感来源）
- **符号锁落位（衔接三表衔接机制）**：分镜表每镜标注本镜出现的符号锁编码（CH-XX/PR-XX/EN-XX/LG-XX，来自小说符号锁资产表与角色锚点编码）；已登记符号必须特征一致，未登记符号不得凭空出现；批产时按编码核对落位
- **与上游的衔接**：分镜表输入 = 剧本（九列核心）+ 符号锁资产表（novel-characters/chinese-novelist 交付）+ 角色锚点与材质参数（novel-characters 交付）；输出 = 画格（visual-storyboard-master 消费扩展字段）与执行稿（cavok-director-os 消费管线/相机/转场字段）——每个字段都有下游消费方，无孤岛字段
