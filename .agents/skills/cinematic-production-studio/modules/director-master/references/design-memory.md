# 模块: design-memory（director-master 子模块，按需加载）

### 惊艳设计速查卡（让产出从合格到有记忆点）

**表演：每个情绪时刻必须有一个'惊喜细节'** —— 观众意料之外但真实的小反应，选一个即可：
- 手的背叛（嘴在笑，手指却无意识揪住衣角/握紧又松开）
- 眼神先于身体（眼睛已经拒绝，身体还维持着礼数）
- 呼吸的泄露（屏息→一次极轻的吸气→再屏住，比表情早半拍）
- 多余的坚持（已经崩溃，仍把某件小事做完：扶正杯子/擦一下根本不脏的桌面）
- 反方向的第一次动作（伤心的人先笑一下；愤怒的人先后退半步）

**动作：必须有一次'节奏反差'** —— 全段不能匀速：
- 慢→爆：压制时的静止（只拍雨滴落下/手指收紧）→ 反制瞬间的急速
- 快→停：一连串急促动作后，突然一个完全静止的节拍（观众屏息点）
- 力量对比可视化：对手发力时主角身体先被'压扁'半秒，再反弹

**张力瞬间（每场动作戏至少一个）**：
- 胜负未分前，一个让观众屏息的'悬置节拍'（手悬在扳机上方/脚踩在边缘/双方同时看向某个东西）

**镜头级记忆点（每场戏至少一个）**：
- 一个非常规角度（贴地、从缝隙、透过前景物体）
- 一个光的意外（唯一的暖色/光被遮住/影子先于身体出现）
- 一个声音的缺席或突袭（本该有的声音消失/不该有的声音出现）

### 顶级专家技法库（从实战高分分镜提炼，六维度通用技法）

**表情/表演**：
- 假笑识别：眼轮匝肌不收缩 = 假笑（真笑眼角有纹）；表演顺序可写'先嘴角后眼睛'制造机械感
- 主观音效：心跳/呼吸错拍让观众'听见'角色的内在异常，比旁白更有效
- 情绪转折用'反方向第一动作'（崩溃前先笑一下）

**动作/身体**：
- 压制戏拍'多余的静止'：动作不动，只拍手指收紧/雨滴落下，张力来自静止而非动作
- 反制前给'悬置节拍'：双方同时分心（听到声音/看见某物）→ 主角抓住 0.5 秒
- 力量对比可视化：发力时身体先被'压扁'半秒再反弹

**分镜/结构**：
- 静态开场用'视觉异常'打破（指节抽搐/水面倒映云动）—— 静中必有暗流
- 声音缺席是强记忆点（嘴在动但无吞咽声/水声在光中消失）
- 意象闭环：开场物件结尾呼应（灯未燃→亮、酒面如镜→活酒）

**机位/角度**：
- 事件开始用'极端角度切换'标记（极高俯拍→急推 = 上天注视的视角）
- 压迫感用仰拍+垂直构图（云绕门走 = 尺度异常制造崇高）
- 低机位贴地拍积水/反光 = 暗示地面是路径/镜像是真相窗口

**特写运用纪律**：
- 特写给'手'比给'脸'更有力（手的背叛：数脉搏跟不上心跳）
- 特写必须携带一个可见细节（指节发白/指尖微颤），不拍空情绪
- 从特写摇出到环境 = 从内心到世界的主观转换

**透视/空间**：
- 用前景小物对比主体尺度（衬衫 vs 巨物）制造奇观
- 画格内唯一亮部指向戏核，其余沉入暗部（光引导视线）
- 空间关系表达权力：高度/距离/朝向（高大者低头=压迫解除）
