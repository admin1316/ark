# 关键帧选择法（每镜该画哪一帧——分镜表与画格的桥梁）

> 来源：行业标准《Professional Storyboarding: Rules of Thumb》(Sergio Paez & Anson Jew) + 动画/真人分镜实践。分镜表必须指定"本镜画哪一帧"——不是画整个动作，是画关键姿势。直接衔接 visual-storyboard-master 画格（画格时知道画什么状态）。

## 核心原则

- 分镜画格 ≠ 动作全程——是**一个瞬间**（关键帧）
- 每个镜头选一帧：**信息最完整、情绪最满、姿势最能说明动作的那一帧**
- 动作序列：画关键姿势，不画中间帧（中间帧交给执行）

## 八类可选帧（按镜头类型选）

### 1. 动作镜 → 关键姿势帧
- 选发力点（即将击出）/平衡点（最高难度的姿态）/接触点（拳与脸相触的瞬间）
- 例：出拳镜画"拳锋触到对方脸颊前一毫米"而非"挥拳过程"
- 连接：与"动作匹配剪"衔接字段配合（上镜结束姿势=下镜起始姿势）

### 2. 情绪镜 → 峰值帧
- 选情绪最满的瞬间（泪落/笑到极致/崩溃前一刻）
- 与表演七段链配合：选"破防"或"余波"帧，不选"蓄力"中间态（蓄力是铺垫，峰值是记忆点）

### 3. 信息镜 → 信息完整帧
- 选能看到关键道具/表情/细节的帧（照片+人物反应同框）
- 检查：观众看这一帧能否get全部信息？不能=换帧

### 4. 对话镜 → 说话帧或反应帧
- 正反打：说话者选"关键台词出口帧"（嘴型+表情同时有信息）；听者选"反应帧"（表情变化）
- 一镜一个视觉重点：说话帧与反应帧不要混

### 5. 转场镜 → 转场起点/终点帧
- 硬切：上一镜末帧=下一镜首帧（衔接字段的 outFrame/inFrame）
- 动作匹配剪：选"两镜共有的那个姿势"
- 叠化：选"两镜中间态"

### 6. 大场面 → 剪影可读帧
- 选轮廓信息最清晰的帧（人物位置/关系/动作方向一眼可辨）
- 远景检查：缩成剪影还能看懂在发生什么？不能=换帧

### 7. 群像 → 关系最清晰帧
- 选所有关键角色位置/关系最明确的帧（谁看谁/谁高谁低/距离）
- 与群像防克隆配合：焦点角色在主体位

### 8. 时间流逝 → 变化最大帧
- 选变化最明显的帧（日落最后一缕光/人物状态最大改变）
- 配合首尾帧锚定：首尾各一帧显示变化过程

## 分镜表落位

- 每镜在"画面内容"列末尾标注：**画格帧 = [类型] + 一句话帧状态**
- 例："画格帧 = 接触帧：拳锋距脸颊 1mm，对方瞳孔放大"
- 检查：画格帧与表演链段位一致（蓄力格画蓄力/引爆格画引爆）；与衔接字段 outFrame 一致

## 自检

1. 每镜指定了画格帧？（没指定=画格环节靠猜）
2. 帧类型与镜头类型匹配？（动作镜用峰值帧=错）
3. 该帧信息完整？（观众一眼看懂发生什么）
4. 与表演链段位一致？与 outFrame 一致？
