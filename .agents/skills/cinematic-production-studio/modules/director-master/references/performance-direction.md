# 模块: performance-direction（director-master 子模块，按需加载）

### 真人表演与微表情硬规则

用户要求表情、哭戏、情绪烘托或真人表演细节时，必须先完整读取 [真人微表情与连续表演合同](../../_shared/micro-expression-performance-contract.md)。每个有人物可读的镜头必须逐角色写清进入状态、刺激来源、认知延迟、眼眉口鼻/呼吸/肩颈/手部的可见变化、角色如何压制情绪、动作结果、余波与退出条件；同时锁定持续时间或帧号。全景用身体与距离，近景用面部，背影用耳/颈/肩/手，不得信息尺度错配。不得让一个镜头同时完成“浅笑、慌乱、蓄泪、落泪、崩溃、嘶吼”的整条链，也不得把“面部细节丰富”等同于强行嚎哭。

### 表演调度细节标准（单人/群体/场景三级，分镜表'画面内容'列按此写）

- **单人特写镜（表演弧线七段，跨镜分配）**：起点→触发→微反应（含一处矛盾微表情：嘴角释然+眼中蓄泪/笑着告别）→蓄力（生理积累：喉结滚动/指节发白/呼吸加重）→破防（引爆帧：眨眼瞬间泪落/无声'嗬'先于哭声）→余波（红肿/清涕/横纹/水丝随呼吸摆动）→收束；**弧线跨镜不跨段**：蓄力格→引爆格→余波格各占一镜，禁止一镜塞完整条链；特写镜按部件清单写（眼/眉/额/唇/鼻/肌肉/生理/声音），每部件一个可验证物理细节
- **群体镜（三级分配+时间差，群像调度必写）**：焦点角色=完整链（占镜内主体构图）；次焦点 2-3 人=简化链（触发→反应→余波），每人 2-4 个关键部件且与焦点呼应/对比（一个哭一个忍/一个上前一个后退）；背景 4+ 人=单细节（一个动作演完态度：筷子停住/伞僵半空/拇指划不动屏幕）；**时间差写进镜头标注**：焦点 0s→次焦点 +0.3~0.8s→背景 +0.5~1.5s；群体情绪用光谱（多数震惊+一人窃喜+一人麻木），禁止全员同质
- **场景调度（环境元素当角色，'画面内容'列可写）**：动态环境元素（雨/灯/蒸汽/钟/风）四要素：初始状态（物理参数）→触发条件→变化过程（时间+物理细节：雨点节奏随抽泣起伏/蒸汽与哭声同步消散）→与情绪关系（呼应/反衬）；一场情绪戏 ≥2 个环境元素，1 呼应 1 反衬；环境变化写进'声音'列或'备注'列
- **景别密度纪律（分镜表画面内容列按景别限量）**：特写=部件级全部件；中景=关键 3-5 项（情绪状态+2 部件+1 生理）；全景=1-2 项（姿态+1 可辨细节）；群像全景=焦点 2 项+背景只给姿态；特写不写整体姿态，全景不写睫毛颤动
- **与角色资产的衔接**：表演细节引用 novel-characters 交付的表演七段链模板/表演锚点/群像定位（焦点型/次焦点型/背景型+反应偏好），不重新设计；缺角色卡时按本标准即时推导并标注

### 工作流纪律

- 严格按步骤顺序执行，不跳步
- 每一步完成后暂停，等待用户的 [通过 / 修改 / 自检] 指令
- 绝不一次性生成所有内容
- 每步结束后提醒用户可以要求 [自检]
