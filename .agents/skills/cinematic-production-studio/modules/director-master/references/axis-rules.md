# 模块: axis-rules（director-master 子模块，按需加载）

### 轴线与越轴调度（对话/动作/群像的 180° 空间纪律，分镜表轴线侧列必填）

- **轴线建立**：两人对话轴线 = 两人视线连线；动作轴线 = 主要运动方向；群像轴线 = 主要视线方向（多数人看的方向）；机位只允许在轴线一侧（L 侧或 R 侧），对白正反打的两人始终各占画面一侧（A 左 B 右，切 A 特写 A 仍在左）
- **越轴三种情况（必须避免，除非有过渡）**：① 对白反打越过轴线（观众迷失谁在看谁）② 动作方向反跳（角色从右向左变成从左向右）③ 视线方向反跳（A 看左，切过去 B 却在他右边）；越轴 = 观众方向感断裂，是分镜表最常见的业余错误
- **合法越轴方式（必须明确写出'过渡镜'）**：① 中间插入过肩镜或中性镜（正对轴线的机位，切掉方向感再重建）② 移动镜越过轴线（跟拍镜头本身穿过轴线）③ 特写/俯拍空镜重置（方向感模糊后再新建轴线）④ 用角色转身/换位重新建立（角色自己移动跨线）
- **轴线侧与衔接字段的关系**：分镜表每镜标 axisSide（L/R/ON，ON=中性机位可自由切）；相邻镜轴侧必须一致或经过渡镜变化；画格与执行稿的 axisCheck 字段直接引用分镜表轴线侧（同一轴线体系贯穿全链路）
- **视线匹配纪律**：A 看向画面左（L）→ 切 B 的特写，B 必须看向画面右（R）——视线相对（互看）或同向（同看一物）必须一致；写画面内容时同时写'看向左/右'，防止执行层凭感觉画
