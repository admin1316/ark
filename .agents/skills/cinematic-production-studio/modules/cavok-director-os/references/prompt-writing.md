# 模块: prompt-writing（cavok-director-os 子模块，按需加载）

### 视频提示词文本层书写纪律（镜头设计完成后的最后一公里，三平台通用）

镜头设计（10 必填字段）决定"拍什么"，本模块决定"提示词文本怎么写"——写错词层，模型按词层执行，字段再准也白搭。

## 一、抽象情绪词禁令（第一大失败源）

禁止在提示词写情绪名词/形容词结果态：恐惧、震惊、悲伤、喜悦、紧张、慌张、绝望、欣慰、犹豫、崩溃、激动、心疼、愤怒、释然、焦虑。

**必须改写为可见生理/行为证据**（可被镜头拍到的）：

| 禁写 | 改写（可见证据） |
|------|------------------|
| 她恐惧 | 瞳孔骤缩，呼吸变浅，喉结上下滚动一次 |
| 他震惊 | 动作骤停 0.5 秒，嘴唇微张，眉心拧起 |
| 她悲伤 | 睫毛低垂，吸气停顿，下唇轻颤 |
| 他愤怒 | 下颌绷紧，指节攥白，鼻翼翕动 |
| 她犹豫 | 手悬停在按钮上方 1cm，拇指微颤，视线在按钮与别处间摆动两次 |
| 他崩溃 | 肩膀塌落，低头，指尖抵住眉心 |

改写规则：一个情绪 = 至少 2 个可见证据 + 1 个时间信息（骤停/0.5秒/两次/悬停/缓/猛地）。

## 二、最终状态直写禁令（时间线过渡）

禁止直接写结果态（"泪水滑落""他倒下""门被推开"）——模型会跳过过程直出结果，画面像 PPT 切换。

**必须写过渡链**：起因 → 起势 → 峰值 → 落点，且每段附时间词。

| 禁写 | 改写（时间线过渡） |
|------|---------------------|
| 泪水滑落 | 眼眶泛红，0.3 秒后一滴泪沿颧骨滑下，在下颌边缘悬停片刻 |
| 他倒下 | 膝部先弯，重心前移，0.8 秒内身体前倾，肩先触地 |
| 门被推开 | 门把手下压，门扇缓慢开启 30°，走廊光先于人影透入 |
| 杯子碎裂 | 手指一松，杯沿先着地弹起，再碎成三片，水花向镜头方向溅出 |

## 三、句子层单动作纪律（一镜一事下沉到句子）

- 每句提示词只写**一个**可见事件（一个主语+一个主动词+一个结果）；动作链用时间词（然后/紧接着/0.5秒后）串联，不用逗号堆叠。
- 反例："她拿起手机，看了一眼屏幕，瞳孔放大，手开始发抖"（4 事件挤一句，模型只执行最后一个或全部糊化）。
- 正例："她拿起手机（0.0-0.8s）→ 屏幕亮起映在她脸上（0.8-1.5s）→ 瞳孔骤缩，手悬停（1.5-2.5s）"（分句+时间窗，每句一事件）。
- 镜头运动与主体动作分两句写，禁止混写（"镜头推近同时她转身"→"镜头缓慢推近；她同时转身"）。

## 四、运动幅度分级（按镜头职责选，稳定优先）

| 级别 | 幅度 | 适用 | 平台建议 |
|------|------|------|---------|
| 微动 | 呼吸级/发丝级/瞳孔级 | 微表情特写/情绪镜 | 可灵低幅度（盐度 0-0.3） |
| 中动 | 转身/抬手/推镜 5-20cm | 叙事镜/对白镜 | 三平台均可，即梦图生视频优先 |
| 大动 | 奔跑/甩镜/全景横移 | 动作镜/转场镜 | 即梦（运镜词识别好）或 Seedance |

写实特写默认微动；幅度越大失败率越高，大动镜必须给"结束姿势"兜底。

## 五、提示词句式模板（三平台按序）

`主体（含角色锚点）→ 单一动作（可见证据+时间词）→ 场景（环境+关键道具）→ 光线（方向/色温）→ 镜头运动（一个动词）→ 质感词（写实/胶片感）`

**自检清单**：①无情绪名词/形容词结果态？②每句单事件+时间窗？③情绪都有 ≥2 可见证据？④过渡链完整（无 PPT 跳变）？⑤镜头运动与动作分句？⑥幅度与镜头职责匹配？——任一不过，回改提示词文本。
