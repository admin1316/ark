# 模块: live-action-texture（cavok-director-os 子模块，按需加载）

### 实拍质感执行要点（视频侧防'AI 味'：胶片/快门/颗粒/光学/动作不完美，与生图侧共用一套逻辑）

- **胶片/机身指定（执行稿头部必写，防'CG 塑料感'）**：选一种影像基底——Kodak Vision3 250D（日光故事片）/ 500T（夜景）/ Fuji Eterna（冷调）/ ARRI Alexa 风格（数字大宽容度）/ RED（锐利）；执行稿写'影像基底：Kodak Vision3 250D'，生成时随提示词下发
- **快门与颗粒（实拍感的时间维度）**：快门 180° 开角（1/48s@24fps）运动模糊是实拍证据，禁止'无模糊的锐利帧'（AI 味来源之一）；胶片颗粒随暗部变粗（'暗部颗粒 > 高光'），数字机写'传感器噪点：暗部 ISO 噪点可见'；过度锐利/全帧清晰 = AI 味，写'克制锐度/焦点外柔和'
- **光学缺陷写入提示词（视频同图，正面描述）**：暗角（四角渐暗）· 高反差边缘紫边 · 特定角度镜头眩光（单点）· 高光软溢出（灯源渐变溢出，不扩散到皮肤）· 暗部分层（深灰保留细节，死黑只允许 ≤10% 且仅光源背面/角落——禁止写'暗部死黑/暗部压缩'这类让整体变黑的词）；'镜头光晕'在 AI 视频里常翻车成满屏光斑——写'单点小眩光'并加入负面'无全屏光晕'
- **动作不完美（视频独有的实拍感）**：真实表演有微瑕疵——眨眼/吞咽/重心微晃/衣料迟后 2-4 帧/头发贴脸；写'自然的微瑕疵'而非'完美的动作'；走路/转身写'轻微不平衡感'（重心转移的瞬间）；禁止'机器人式完美动作'（无惯性/无重量感）
- **曝光行为（视频同图）**：高光溢出只给光源本身；暗部写'深灰层次'（主体中间调清晰，死黑限量给角落）；白平衡允许整体微偏（暖偏/冷偏是实拍的）；运动模糊角度=快门角度；负面清单加'无整体过暗/无死黑一片'
- **主体亮度锚点（防视频太暗，第 8 条光色必写）**：暗环境+亮主体——执行稿光色段先写主体亮度（'面部中间调清晰明亮''主体受光充足五官可辨'）再写环境（'环境深灰层次'）；暗场景镜（夜戏/烛光）必须显式写'主体明亮可辨'；暗词限制：'暗部/阴影/夜景'类词每镜 ≤3 个；连续暗场镜 ≤2 个，第 3 个前必须提亮或插入亮场镜
- **执行稿落位**：影像基底/快门/颗粒/光学缺陷写进执行稿头部'影像系统'段，随第 8 条光色一起输出；负面清单固定加'无塑料皮肤/无过度锐利/无完美动作/无全屏光晕/无CG感'

- **与上下游的衔接**：输入 = director-master 分镜表（九列+扩展字段）与 novel-characters 角色材质参数（皮肤 SSS/布料粗糙度/金属 IOR 直接落执行稿）；输出 = 成片质检（short-drama-ai-suite 质检链路核对管线/相机/衔接是否照稿执行）
