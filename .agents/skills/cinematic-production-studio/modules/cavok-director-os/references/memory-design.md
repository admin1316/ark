# 模块: memory-design（cavok-director-os 子模块，按需加载）

## 惊艳设计速查卡（让执行稿从合格到有记忆点）

**表演（真人/动画通用）：每个可读镜头至少一个'惊喜细节'**：
- 手的背叛（嘴在笑，手指却无意识揪住衣角/指甲掐进掌心）
- 眼神先于身体（眼睛已经拒绝，身体还维持着礼数）
- 呼吸的泄露（屏息→极轻吸气→再屏住，比表情早半拍）
- 反方向的第一次动作（崩溃的人先笑一下；愤怒的人先后退半步）

**动作：全段必须有至少一次'节奏反差'**（慢→爆 或 快→停）：
- 压制时静止（只拍雨滴/手指收紧）→ 反制瞬间急速
- 一连串急促动作后一个完全静止的节拍（观众屏息点）

**张力瞬间（每场动作戏至少一个）**：胜负未分前的悬置节拍（手悬在扳机上方/双方同时看向某处/脚踩在边缘）

**镜头级记忆点（每场至少一个）**：非常规角度（贴地/缝隙/透过前景）· 光的意外（唯一暖色/光被遮住/影子先于身体）· 声音的缺席或突袭

### 顶级专家技法库（透视/空间/特写维度）

**透视/空间**：
- 用前景小物对比主体尺度（晾衣绳衬衫 vs 巨物）制造奇观与敬畏
- 低机位贴地拍积水反光 = 暗示地面是逃脱/真相路径
- 空间关系表达权力：高度/距离/朝向（高大者低头=压迫解除；两人之间的空隙=关系裂痕）

**特写纪律**：
- 特写给'手'比给'脸'更有力（手的背叛：身体先于意识暴露异常）
- 特写必须携带一个可见细节（指节发白/指尖微颤/揪裙缝），不拍空情绪
- 从特写摇出到环境 = 从内心到世界的主观转换（可配声音主观化：外界变浑浊）

**光色专家级**：
- 全片冷调时，唯一暖色 = 危险的信号（'暖色即危险'，留给关键物件）
- 声音缺席是强记忆点（嘴动无吞咽声/水声在光中消失）
