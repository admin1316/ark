# 模块: platform-grammar（cavok-director-os 子模块，按需加载）

### 三大平台提示词语法速查（即梦 / 可灵 / Seedance，执行稿按目标平台落语法）

- **通用提示词结构（三平台都认，按序写）**：主体（谁，含角色锚点特征）→ 动作（一个主要事件，动词开头）→ 场景（环境+关键道具）→ 光线（方向/色温/质感）→ 镜头运动（一个，不叠加）→ 氛围质感（写实/电影感/风格词）；4 秒镜最多 3 个动作节点，动作间因果连续；禁止'氛围词堆砌'（'史诗级/震撼/唯美'不算内容）
- **即梦（Jimeng）语法**：中文提示词为主，支持文生视频/图生视频/首尾帧模式；镜头运动用明确动词（'镜头缓慢推近''固定机位''环绕主体'），支持 4s/8s/10s 档位；图生视频模式优先（首帧锚定人物与场景，文字只描述运动与变化——即梦对'图片已锁定内容'比纯文字稳定）；**首尾帧模式**：首帧/尾帧各给一段描述，中间过渡交给模型，两帧差异越大风险越高（差异控制在'同一构图内的状态变化'）；负面提示：多指/变形/水印/文字乱码/人物突变
- **可灵（Kling）语法**：提示词中文，支持文生视频/图生视频/首尾帧；**运镜控制词**（推进/拉远/左移/右移/上移/下移/环绕/跟随/固定）写进提示词或参数区；专业模式可调运动幅度/盐度（幅度越高越动感也越易崩，写实特写建议低幅度）；5s/10s 档位；图生视频适合延续上一镜（可灵对运动幅度敏感，微表情镜用低幅度）；负面提示：变形/穿帮/多余肢体
- **Seedance（字节豆包）语法**：中文提示词；支持镜头运动描述（推近/拉远/旋转/平移）；适合长动作链（多节点动作可 4-10s 完成）；场景与角色分开描述（'角色：… 场景：… 镜头：…'分段式结构可提高遵循度）；首尾帧/图生视频可用；负面提示：角色变形/背景跳变/文字乱码
- **平台选择逻辑（按镜头职责选）**：微表情特写/细腻表演 → 可灵低幅度图生视频（运动幅度可控）；连贯多节点动作（端面放碗抬头）→ Seedance（长动作链强）或即梦图生视频；快速甩镜/大运动 → 即梦（运镜词识别好）；三平台都出的情况下，先出 1 条 4s 测试再批量
- **执行稿落平台（产出格式）**：执行稿末尾标注'目标平台：X + 模式（文生/图生/首尾帧）+ 档位时长 + 提示词全文'，提示词全文 = 上述通用结构按平台语法改写版；同一镜给三平台时，主体/动作/场景/光线描述保持一致（跨平台资产一致），只改镜头运动与结构格式
