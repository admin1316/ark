# 短剧 AI 制作套件（short-drama-ai-suite）

把小说、故事大纲或短剧需求转化为短剧/漫剧剧本、角色与场景资产方案、电影分镜、Seedance/可灵/Pika 等视频提示词及连续性检查。

## 用法

直接说出任务即可（小说改编、爆点钩子、角色卡、场景设计、分镜、首尾帧、AI 视频提示词、画面风格等），或显式调用：

```text
使用 $short-drama-ai-suite 把这段小说改编成 9:16 竖屏漫剧前 3 集的节拍图和分镜提示词。
```

本技能所有技法均为技能内置原创内容，无需外部素材库：三表衔接机制（符号锁迁移/悬念曝光五级/钩子动力学）、爆点节奏表、名场面设计工程、真人短剧 vs 漫剧双轨、真人写实表演细节标准、镜头职能分配制、曝光设计、AI 视频镜头衔接、电影级渲染规格书与可执行参数层、声音设计三层、成片质检链路。
