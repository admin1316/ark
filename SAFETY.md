# Safety boundaries

English | [中文](SAFETY.zh.md)

DeepSeek Harness is a developer preview and has not undergone an independent security audit. Sandboxing, approvals, and permission controls reduce risk but do not guarantee complete isolation.

Run only trusted workspaces, plugins, MCP servers, and commands. Review the requested permission level before use, keep credentials out of prompts and repositories, and treat full-access execution as equivalent to running local code with your account's privileges.
